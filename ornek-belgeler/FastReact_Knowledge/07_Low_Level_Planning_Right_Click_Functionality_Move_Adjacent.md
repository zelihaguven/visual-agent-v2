# Main Menu - Low Level Planning - Right Click Functionality - Move Adjacent

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Low Level Planning > Right Click Functionality > Move Adjacent

---

## Move adjacent strips on this row.

[Screenshot: LL RC Move adjacent]

This option allows the user to pick up, in one go, strips that are of the same Order, Product or Customer, then plan them all on a different row. This option also allows the user to configure their "pick up" criteria:

[Screenshot: LL RC Move adjacent]

This dialog allows the user more options for the strip pickup criteria.
