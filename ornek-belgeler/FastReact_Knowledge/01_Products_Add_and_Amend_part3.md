# Main Menu - Products - Add and Amend (part 3)

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Products > Add and Amend
**Part:** 3 of 3 — sections: Rename, Copy, Inheritance

---

### Rename

*Context: Main Menu > Products > Add and Amend › Add & Amend › Rename*

You can rename products at any time.

**Select a product to rename:** This is a list of existing Orders. Select the Order you want to copy from the incremental search list.

**Enter a new name:** Enter a new order name here. FastReact will validate the new order and only allow a rename to be made if the new order reference does not already exist.

**Rename (button):** This button will rename the selected order.

### Copy

*Context: Main Menu > Products > Add and Amend › Add & Amend › Copy*

This is used to copy one product's information to another. This could be useful if you have many products that have the same base information, reducing some of the keying in that is required. (You could also use product data inheritance below).

**Select a product to copy:** Select the product you want to copy from the incremental search list.

**Copy product to:** Enter the new product name, up to 30 characters long.

**Copy (button):** Click here to create the new product.

**Copy events (button):** This will copy the product details as above but will also copy the current event progress.

##### What to Inherit

Normally when a product is copied, all data from the source product will appear in the new product. Subsequent changes to the source product will not be propagated to the new product. However, by using inheritance, you can force changes in the source product to propagate into all products that have been inherited from that source.

**Inherit work content (defaults to copy):** When this option is enabled all work content values will be inherited from the source product.

**Inherit materials (defaults to copy):** When this option is enabled all materials used will be inherited from the source product.

**Inherit property:** When this option is enabled the product property text string will be inherited from the source product.

**Inherit launch date:** When this option is enabled the product will inherit the launch date from the Parent Product.

### Inheritance

*Context: Main Menu > Products > Add and Amend › Add & Amend › Inheritance*

This option allows you change the data inheritance for existing products.

**Select a product to change:** You can select a single product from the incremental search list or you can enter a value including wild card characters. This will allow update of multiple products using wild card matching.

**Inherit details from:** Select a product to inherit from using the incremental search list.

**Inherit (button):** Click here to initiate inheritance.

##### What to inherit

**Inherit work content (defaults to copy):** When this option is enabled all work content values will be inherited from the source product.

**Inherit materials (defaults to copy):** When this option is enabled all materials used will be inherited from the source product.

**Inherit property:** When this option is enabled the product property text string will be inherited from the source product.

**Inherit launch date:** When this option is enabled the product will inherit the launch date from the Parent Product.
