# Main Menu - Tools - Process Remote Response

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Process Remote Response
**Index keywords:** Process Remote Response

---

## Get Remote Replies

This option is used in conjunction with the Remote Data Requests. It allows the user to receive the returned data back into the Host system

### Retrieve replies

**Retrieve replies (button):** This button will access the email system setup under the Setup menu.

## List of replies

If there are no replies a message will appear stating this, if however there are replies then a list of these replies will appear in the text field below the Retrieve replies button. Double clicking the required reply will automatically open up the Review/Process dialog. See below.

### Review/Process

**Order/Product:** This is a list of all the Orders/Products that have been altered at the remote site.

**Updated:** This field identifies what has been updated, e.g. planned operation, operation etc.

**Status:** This is the status of the Order/Product.

**Quantity:** This is the amount, if any, that the Order/Product has been updated by.

**Transport:** The transport method of the Order/Product.

**Date updated:** The date that the update took place.

**Notes:** Any notes recorded by the remote site.

**Updated by:** Who updated the Order/Product.

Each Order/Product can be selected individually from the list using the check boxes.

**Select All (button):** - [Icon: Select All] Select all.

This button will select all of the available Orders/Products.

Select None

- [Icon: Select None] Select none.

This button will de-select all the selected Order/Products.

Invert Selection

- [Icon: Select Some] Invert selection.

This button will de-select any selected Order/Product and select any de-selected Order/Product.

**Process Selection (button):** This button will incorporate the selected Order/Product updates into the host plan.

**Print (button):** The Review/Process list can be printed out.
