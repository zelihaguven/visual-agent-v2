## Chat Messaging

*Context: Functionality > Chat Messaging › Chat Messaging*

### Introduction

*Context: Functionality > Chat Messaging › Chat Messaging › Introduction*

Evolve and Align have the ability to perform Chat Messaging between Fast React users. This licence option allows the FR Users to send, via the FastReact environment messages to each other. These messages are, dependant upon which area of FR the messages are being sent from, and relate to either the Order, Product and Order/Product Events.

When a user logs on to FastReact there will be a new icon on the main FastReact screen in the bottom right hand corner:

- [Icon: Chat No Message] No Unread Messages
- [Icon: Chat New Message] New Unread Messages

### Messaging from the FR main screen

*Context: Functionality > Chat Messaging › Chat Messaging › Messaging from the FR main screen*

Messaging can be done via the message icon found on the bottom of the FastReact application screen: [Screenshot: Chat No Message]

The user can send and receive short messages from here. Clicking on the icon brings up the Message grid. In here the user can see messages that have been sent from or to him/her.

#### The Chat Inbox

*Context: Functionality > Chat Messaging › Chat Messaging › Messaging from the FR main screen › The Chat Inbox*

[Screenshot: Chat Inbox]

The user can “reply” to existing messages via the Reply button or can start a new message chain by clicking on the “New Message” button.

#### New Message

*Context: Functionality > Chat Messaging › Chat Messaging › Messaging from the FR main screen › New Message*

When creating a New Message from the FR Main Screen, the user must enter:

1. Who the message is to.
2. The Note type:

 1. Product.
 2. Order.
 3. Product Event.
 4. Order Event.

3. The Product or Order name that the Note is about.

4. The message that the user wants to send.

[Screenshot: Chat main new message]

Notes will now appear in the Inbox tab.

[Screenshot: Chat Inbox]

### Product - Chat

*Context: Functionality > Chat Messaging › Chat Messaging › Product - Chat*

From the Product - Notes dialog the user can also initiate a send a Chat Message. Click on the Chat Message icon [Screenshot: Chat Icon] will open up a the Send dialog.

#### Send Note To User

*Context: Functionality > Chat Messaging › Chat Messaging › Product - Chat › Send Note To User*

In this dialog the user can choose whom to send the message to and also type in a short message:

[Screenshot: Chat Product]

Clicking on the “Send” button will send the message to the selected recipient and the recipients FastReact system will display the “new message” icon on the main page indicating that there is a new message for them to read.

[Screenshot: Chat New Message]

### Event - Chat

*Context: Functionality > Chat Messaging › Chat Messaging › Event - Chat*

Chat Messages chat also be initiated at the Event level via the Event by Item screen and the Note icon to the left of the event name:

- [Icon: New Note] New Note against the Event
- [Icon: No Note] No Note against the Event

#### Messaging from Event - Notes

*Context: Functionality > Chat Messaging › Chat Messaging › Event - Chat › Messaging from Event - Notes*

Chat Messaging from the Event by Item dialog works in exactly the same way as from Order or Products. The only difference is that the user has to click on the Note icon to enter the Event Note screen. From there Chat Messages can be sent.
