# Functionality - Batch Tickets

**Source:** FastReact Help (version 4.44) — Functionality / concepts
**Menu path:** Functionality > Batch Tickets
**Index keywords:** Batch Tickets

---

This functionality allows FastReact to generate and record a series of unique ID’s, “Ticket ID’s”, against each FastReact Order, Group and Row. Each ticket will represent a finite production quantity (a batch).

The Ticketing System allows the User to create printed tickets containing the Ticket ID’s plus other key production information. The reporting also allows the User to create a bar code based on the unique Ticket ID plus other key fields. This will allow production progress for a Product on a particular machine to be passed to a Shop Floor Data Collection unit, inclusive of the unique Ticket ID. The Ticket ID and quantity can then be passed from the SFDC to the business system and hence to FastReact in order to update progress on the appropriate FastReact planning Order.

The layout of the printed ticket will be created to match existing template or can be configured however the Client requires. The barcode generated from the data will use Code 39 barcode fonts.
