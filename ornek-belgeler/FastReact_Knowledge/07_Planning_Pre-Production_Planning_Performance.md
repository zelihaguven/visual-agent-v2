## Performance

The diagram below illustrates the Performance of the Executives to complete Events.

The first graph shows the Number of Events against the Days in Hand. This allows the user to see at a glance when events were completed.

The second graph shows the Complete Events Statistics and as such displays the number of events Completed on time and Late.

[Screenshot: Performance]

Clicking on any of the Bars in both of these graphs will display the Pre-production events relating to that Bar.

For example, clicking on the 'On Time' Bar will filter the Pre-production planning board to show only all the Events that were completed On Time.
