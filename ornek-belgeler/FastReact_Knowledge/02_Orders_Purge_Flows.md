# Main Menu - Orders - Purge Flows

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Orders > Purge Flows
**Index keywords:** Purge Flows

---

## Purge Flows

Purging flows enables the planner to delete a number of flows at once. Flows cannot be purged if there are any orders attached to them.

Warning: - Purging will permanently remove Flows.

> **Note:** The Purge Orders option will be grayed out (disabled) whilst either the High Level or Low Level Planning boards are open. This is to ensure data integrity.

### Remove

#### Which flows would you like to delete.

**All:** This option will delete all the flows from the database. However, flows which are attached to an Order cannot be deleted.

**Wild card matching:** This option will delete all the flows from the database that match the entered wild card(s).

**Specify:** The required flow name with the wild card (a wild card is either '\*' or '?') is entered here.

**Purge flows (button):** This button will remove the selected flows. FastReact will give a count of the flows that are about to be removed and ask for confirmation before actually deleting them.
