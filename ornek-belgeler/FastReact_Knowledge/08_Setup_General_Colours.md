# Main Menu - Setup - General - Colours

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Colours
**Index keywords:** Colours

---

## Master Colour List

This dialog is only available when the user has Supervisor rights. It allows the user to define a set list of colours which can be used in the Costings and or Purchase Orders modules.

### Colours

The Colours list is a master list of colour names.

**Colour name (column 1):** The name of the desired colour. New colours are entered in this field. To delete a colour, clear the entry in this field.

**New name (column 2):** This field is used to rename the colour in the Colour Name field.

**Update/Insert (button):** This button will update or insert the Colour.

**Add to list (button):** This button will add new fields to the Master Colour List.
