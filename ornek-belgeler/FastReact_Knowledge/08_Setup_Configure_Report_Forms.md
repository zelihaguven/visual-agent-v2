## Report Forms

With the introduction of the Purchase Order, the Material Purchase Order and the Batch Ticketing modules, FastReact has the ability to produce reports with a client defined Layout and style.

These Reports are created by Fast React personnel and are only used for PO, MPO or Ticketing purposes.

### Report list

This is a list of the PO reports that Fast React have created.

**New .... (button):** Create a new PO report. This should only be done with the help or by a FR representative.

**Delete (button):** Delete the selected PO report.

**Preview (button):** Preview the selected PO report.

**Design (button):** Go to the Design (layout) of the selected PO Report.

**Export ... (button):** Export the selected PO Report.

**Import (button):** Import a PO Report.
