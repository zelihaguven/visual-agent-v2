Release Notes Evolve 4.39

Release Notes for FastReact Evolve version 4.39

Version Number 1.9

We are pleased to announce the release of FastReact Evolve & Align 4.39 to all our customers. This new release is freely available to all users with a valid support and maintenance contract. FastReact 4.39 contains a range of new features, general enhancements and fixes. You may already have an interim version containing some of these new options but may be unaware of all of the extra features. This release upgrades version 4.38.

The following document aims to highlight the main changes and enhancements plus a list of resolved issues. Some of the features and functions below are licenced options so if you have any questions regarding the features and fixes detailed in this document please contact your Account Manager to arrange an overview or a detailed training session.
