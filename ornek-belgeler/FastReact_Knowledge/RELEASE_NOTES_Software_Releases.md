## Release Notes

Each release has a new identification which can be seen either in the FastReact About dialog or in the Version properties shown by Windows. The release number will be in the following format v.r.dbb.n where:

- v - Shows the major version of FastReact. The current version, known as 'Evolve' or 'Align', will always be version 4.
- r - Release number.
- d - Day number. This is day of the quarter. For a branch this will be the day number of the origin of the branch.
- b - Branch. This is used for client specific numbered branches. Under normal circumstances this will be "0" indicating a Release, anything other than "0" will indicate a Branch build.
- n - Incremental number.

The Table of Contents lists the new releases in reverse order with the latest release at the top.
