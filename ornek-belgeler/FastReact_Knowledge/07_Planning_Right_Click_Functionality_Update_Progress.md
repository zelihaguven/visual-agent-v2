# Main Menu - Planning - Right Click Functionality - Update Progress

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > Right Click Functionality > Update Progress
**Index keywords:** Updated Progress

---

[Screenshot: Update progress]

This option allows the planner to update the progress of each non-planned operation without having to navigate away from the Planning Board. Clicking on this option displays the dialog below:

[Screenshot: Update progress]

The yellow highlighted line indicated that the Production Update dialog has been opened whilst the Planing Board is open by the same user. Production Updates can be manually entered when the Planning Board is open however they will sit in the Pending column untill the planning board is closed.
