## Events report

[Screenshot: LL RC events report]

When selected the dialog screen below will open.

Within this screen the planner can see the critical path event progress on the selected Order/Strip. This option details all outstanding events and all completed events along with the target dates and if the event is on time or late. Negative figure indicate that the event is over due (late) for completion.

[Screenshot: LL RC events report]

FastReact allows the user to toggle between "outstanding events" and "Completed events" by clicking on the relevant tab.

Upon clicking on the Update button the planner will be able to update the Production Events and, if there are any, the Development Events. If there are no Development Events associated with this Strip then the Development Events tab will be hidden.
