# Main Menu - Help - Support

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Help > Support

---

## Fast React Systems Support Desk

This option allows the user to send an emailed support request message to your Fast React support provider. The Email address is setup on the Error Logs tab of the Email dialog. By default this will be set to "[support@FastReact.com](mailto:support@fastreact.com "Send an email to Support")".

### Send to support

A message to the Fast React Support Desk can be included with the support request email.

#### What to send

There are three options:

**No data (default):** The email will just request help form Fast React Support. No data will be sent with the email.

**Audit log only:** The email will request help from Fast React Support and include the Audit log as part of the email.

**All tables except:** Optionally, a copy of the current database can be attached to the email. This can be invaluable in helping Fast React Support analyse the problem.

**Strip data backup:** Selecting this option will force FastReact NOT to send the _Strip_data_backup table.

**KPi data:** Selecting this option will force FastReact NOT to send the KPi history tables.

**Send to Fast React Support (button):** This button will create and send the support request email, along with any messages and/or data.
