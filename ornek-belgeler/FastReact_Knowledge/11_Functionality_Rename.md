## Rename.

This facility may be used to rename objects such as orders, products or customers. Objects can be renamed at any time without affecting data integrity in any way.

### Select the object to rename

Choose from the list of previously defined objects.

**Enter a new name:** Enter the new name of the object.

**Rename (button):** This button will only be active when an object is selected and you have entered valid new name. Click the button to save the changes.
