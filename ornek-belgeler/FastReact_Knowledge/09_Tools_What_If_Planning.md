# Main Menu - Tools - 'What If?' Planning

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > 'What If?' Planning

---

## Create/Remove 'What If?' Databases

#### Introduction

FastReact can perform ‘What-if?’ planning, enabling the planner to make changes to the data and review the effects without changing the live system. This facility works by letting the planner create a copy of the database in which to test the changes. The planner must have supervisor rights to use this facility.

#### Copying the database

The ‘What-if?’ databases is created from the Main Menu - Tools - ‘What-if?’ Databases menu option. When the planner creates a new database there may be a need to enter some further information, depending on the type of database being used.

**Microsoft Access::** There is no need to enter any further information as the database file name and directory will automatically be completed.

**Microsoft SQL Server::** There may be a need to enter a server name if the planner is copying from an Access database and there will be a requirement to enter directory names for the database and log files, and also a system administrator password. The SQL Server Database Administrator will be able to help with all of these.

Once the new database is created, FastReact will copy all data from your existing database and reminded the planner of the database expiry date. ‘What-if?’ databases are only useable for a limited period of time. After creation of a ‘What-if?’ database the planner must log out of FastReact before using it.

#### Using the database

If there are any ‘What-if?’ databases set up in FastReact then, as the planner logs in, he/she will be prompted to select one. The planner can select any of the un-expired databases or select Cancel to use the live system. Once the planner has logged in, the name of the ‘What-if?’ database will be displayed in the title bar and FastReact can be used as normal.

#### Expired databases

Once a ‘What-if?’ database has expired the planner will not be able to use it any further and it can be deleted from the Main Menu - Tools - ‘What-if?’ Databases menu option.

### What if? Databases

**Databases:** This is a list of all the ‘What-if?’ databases

**Access file:** This is the name of the Access database file.

**Expires after:** This is that date on which the ‘What-if?’ database expires.

**New (button):** This button will create a new ‘What-if?’ database.

**Delete (button):** This button will delete the selected ‘What-if?’ Database.

### Rename

Renaming of a ‘What-if?’ Database can take place at any time.

##### Select an database to rename

This is a list of existing ‘What-if?’ Database. Select the ‘What-if?’ Database that requires renaming from the incremental search list.

**Enter a new name:** Enter a new ‘What-if?’ Database name here. FastReact will validate the new ‘What-if?’ Database and only allow a rename to be made if the new ‘What-if?’ Database reference does not already exist.

**Rename (button):** This button will rename the selected ‘What-if?’ Database.
