## Populate Test Database

This dialog will allow an admin user to create an identical Test SQL system on their Network. See Functionality - Test Databases for more information.

### Populate test database

**Database:** This is the name of the already created Test Database instance. When first setting this up it MUST be a blank database.

**Server name:** This is the server name of the SQL Server that the above DB instance is on.

**Login name:** In most circumstances, this will be 'fastreact'.

**Populate (button):** This button will begin the "population" of the Test database from the current Live system.

> **Note:** This may take quite some time depending upon the size of the Live database.
