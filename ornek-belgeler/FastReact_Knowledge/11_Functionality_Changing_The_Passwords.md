## Changing the Passwords.

Each user must have their own password to gain access to FastReact.

Passwords must be between 3 and 15 characters long and are not case sensitive. By default all newly created users will have the password of 'password' until they amend this.

Users can change their own passwords through the Main Menu - Setup - Security - Passwords menu. Since most users do not have access to the security menu they can access the password screen only by pressing [Ctrl]-[Alt]-[P].
