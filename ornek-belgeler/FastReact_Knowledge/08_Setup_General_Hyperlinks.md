# Main Menu - Setup - General - Hyperlinks

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Hyperlinks

---

## Hyperlinks

Hyperlinks allow for the configuration of external information associated with Order and Products allowing the user to add their own specific external links to these records.

### Define

#### Select a Hyperlink type to change

**Orders:** This option allows the user to enter a list of Order related Hyperlink fields. Select the Order from the list and type in the name in the column labelled 'Enter field name'.

**Products:** This option allows the user to enter a list of Product related Hyperlink fields. Select the Product from the list and type in the name in the column labelled 'Enter field name'.

**Enter field name:** New Hyperlink fields are entered here or one can be selected from the list bellow. The field name may be up to 15 characters long. Fields can only created or deleted here. If a User defined field is deleted, then all data associated with it within the Order or Product records will also be deleted.

**Enter a new name:** This option allows you to rename a selected Hyperlink field. Select the required Hyperlink field from those that have previously been entered and type a new name in the field labelled 'Enter a new name'.

**Rename (button):** This button will rename the selected Hyperlink.
