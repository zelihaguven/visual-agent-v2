# Main Menu - Setup - General - Suppliers

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Suppliers
**Index keywords:** Supplier

---

## Suppliers

Suppliers are used when entering material details (stock and availability) into FastReact, also in the materials requirements calculations, materials planning and Costings.

### Define

**Supplier name:** Enter the name of a new supplier or select a supplier from the list. Supplier names may be up to 15 characters long.

**Description:** A description of the Supplier.

#### Contacts

**Postal address:** This field will hold the full postal address of the selected Supplier.

##### Contacts:

**Name:** The name of the contact.

**Email:** The email address of the contact.

**Telephone 1:** The primary telephone number of the contact.

**Telephone 2:** The secondary telephone number of the contact.

**Telephone 3:** The tertiary telephone number of the contact.

These fields will hold the relevant email addresses for the selected Supplier. The user can enter up to 5 email address per supplier.

#### General

**Country:** This drop down menu will hold a list of pre-defined Countries.

**Supplier type:** This is a list of pre-defined shipping types.

**Normal transport:** This drop down menu will hold a list of pre-defined Transport methods.

#### Financial

Each Supplier will be associated with a defined Payment Terms to allow for different duty and freight payment points according to country of origin (COO) in a dialog similar to the following.

**Payment Terms:** This drop down menu will hold a list of pre-defined Payment Terms.

**Currency:** This drop down list contains the Currencies as relating to the Payment Term.

**Commission:** This drop down list contains the Commission value as relating to the Payment Term.

**Raw material supplier:** The supplier can be marked as a raw material supplier.

#### Transport costs

This is a transport cost matrix based upon Product type and Transport method.

**Product type:** This is a list of pre-defined Product types.

**Transport method:** This is a list of pre-defined Transport methods.

**Insert / Update (button):** This button will insert a new supplier or update an existing supplier.

**Delete (button):** This button will delete the currently selected supplier.

#### Rename

Renaming of a Supplier can take place at any time.

**Supplier name:** This is a list of existing Supplier. Select the Supplier that requires renaming from the incremental search list.

**New name:** Enter a new Supplier name here. FastReact will validate the new Supplier and only allow a rename to be made if the new order reference does not already exist.

**Rename (button):** This button will rename the selected Supplier.
