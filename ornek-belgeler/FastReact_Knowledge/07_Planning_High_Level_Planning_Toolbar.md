# Main Menu - Planning - High Level Planning - Toolbar

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > High Level Planning > Toolbar

## Toolbar

*Context: Main Menu > Planning > High Level Planning > Toolbar › Toolbar*

The High level planning board has a tool bar running across the top of the screen and this provides access to a number of commonly used functions. Many of these functions can also be used via the keyboard as shown below.

- [Icon: Delete] Close the planning board.

Keyboard = None

Click here to close the planning board. If there are any changes to the plan that have not been saved then FastReact will ask if to save the plan before closing.

- [Icon: LL planned] View planning board.

The High level board is a split screen showing, at the top, the planned strips and at the bottom, the loading on the planned groups. Click here to expand the planning board to cover the whole screen.

Keyboard = Space bar

- [Icon: HL mix view button] Split screen.

Click here to show both the planning board at the top and the loading charts at the bottom.

Keyboard = Space bar

- [Icon: HL Bucket] View group loading.

Click here to expand the group loading charts to the full screen.

Keyboard = Space bar

- [Icon: ExpandContract] Change the time scale.

This button will change the 'Date' scale resolution. These buttons reduce or increase the scale to show a longer or a shorter period of time. The maximum is about 6 months in weekly increments (depending on monitor size and resolution), and the minimum is just over a day When the scale is at its extremes the buttons are disabled.

Keyboard = Ctrl - Left arrow, Ctrl - Right arrow

- [Icon: Up Down] Change row height on the planning board.

This button will reduce the height of planning board row. A smaller height will allow more rows to be displayed but give less information. At its maximum FastReact displays additional information between the strips. On normal resolution (1024 x 76) you should be able to see about 20 rows at maximum height and 30 rows when at minimum.

Keyboard = Ctrl - Up arrow

- [Icon: Reduce Increase] Reduce/Increase the Plan bucket.

This will change the time shown within each period on the planning board. Possible values are Daily, Weekly, Monthly, Financial months\* and User defined periods\*.

These options require that you configure special calendars else the display could be unpredictable.

Keyboard = Ctrl - PgUp/PgDn

- [Icon: Return to todays date] Home.

Press the Home key to position the plan on the first planning board row and the first group and aligned with Today. In a split screen mode you can force the Home key to act on the Load charts by holding down the Shift key. Otherwise the Home key will act on the planning board.

Keyboard = Left and Right arrows.

- [Icon: Left Right Move] Scroll left, scroll right.

Scroll the planning board to the left and right to show different periods of time.

Keyboard = Left and Right arrows.

- [Icon: Forecast icon] Forecasting.

This option will open the forecasting dialog.

- [Icon: Forecast HL icon] High Level Forecasting.

This option will open the high level forecasting dialog.

- [Icon: Bar charts] Show operation loading bar charts.

Click on this button to activate the Operation Loading Bar charts to show other operation loading. The drop down menu offers the ability the create and save Bar chart sets.

- [Icon: Image Attach] Image display.

Click on this button to activate the Image display against strips. The image will be displayed whenever the cursor rolls over a strip.

Keyboard = None

- [Icon: Find] Find.

This option is provided to help you to easily locate orders on the planning board. For more details click here.

Keyboard = F4

- [Icon: Sort display] Sort display.

You can sort the planning board in a variety of ways.

Keyboard = None

- [Icon: display rotation] Rotate display.

FastReact can display different types of information and colour codes for your orders. The display rotation will affect the information that is displayed down the left of the planning board and the colour of the planning board strips. Click on the attached drop down menu to select the required display type.

Keyboard = None

- [Icon: Consolidate plan] Consolidate plan.

The loading and capacity of individual planning groups can be 'rolled up' in a number of different ways. Click on the attached drop down menu to select the required consolidation type.

Keyboard = None

- [Icon: Lock] Show locked groups.

The high level planning board may be opened by several planners at the same time. Some groups may be locked by one planner whilst others may be locked by another planner. These groups will show a padlock and orders on these groups can not be moved by other planners. Such locked groups may be hidden from view, or shown, by clicking this button.

Keyboard = None

- [Icon: Document1 Attach] Reload board.

Click this button to reload the planning board from your hard disk. You could use this feature if you want to undo many changes. Before reloading your plan FastReact will ask you to confirm that you want to lose your changes.

Keyboard = None

- [Icon: Save report] Save changes.

Click here to save any changes that you have made to the plan in the current planning session. If you do save the board then the undo function and reload board function will be disabled.

Keyboard = None

- [Icon: Redo report] Undo strip movement.

Click on this button to undo strip movements. FastReact stores an unlimited list of movements When there are no more changes to undo the button is disabled.

Keyboard = Alt - Backspace

- [Icon: Load List] Load new order.

Click here to access to the Load List, a list of orders still to be planned onto the board. The dialog also shows orders that are in any Low Level planning board load lists. This helps to find orders that would otherwise not be visible on the High Level plan. When the both High Level and Low Level lists are empty this button is disabled.

Keyboard = None

- [Icon: Realign icon] Realign strips.

This button will realign the selected strips to their Critical Path dates.

Keyboard = None

- [Icon: JiT] JiT autoload.

This button allows the planners to JiT autoload strips in the High Level Load List and re-plan strips already on the High Level board. This button is only available when JiT autoloading is licenced and enabled.

Keyboard = None

- [Icon: JiT Options] JIT move selected strips.

This button allows the planners to JiT re-plan strips already on the High Level board. This button is only available when JiT autoloading is licenced and enabled. The High Level Drop Down option also need to be enabled, although this does not require activation on the Planning Board.

Just in time

This will move all the planned strips to Just in Time based upon their delivery date.

Remove overhang

This will move the strips so that late events are no longer late.

Warning:

This option MUST only be used after careful discussion with FRS as it will have serious implications with regards to planning.

Keyboard = None

- [Icon: Plan Sections] Section to view.

In a cascaded system, this drop down list shows your sections. Select from the list the planning section that you wish to view at high level. By selecting the ‘\*’ all sections will be displayed, however the Load List will be disabled.

Keyboard = None

- [Icon: Auto Refresh] Refresh button.

Because FastReact is a multi user system there may be changes made by other users that could affect planning decisions. FastReact will check periodically to see if there are any such changes waiting to be incorporated into the plan. If this button, which is normally Green, changes colour then click on it to incorporate the new changes. If the button turns Yellow, the changes can be incorporated immediately. If it turns Red then the planning board must be saved before FastReact will allow the changes to be incorporated.

Keyboard = None

- [Icon: Save Plan] Save Plan.

This button will save the current plan. The button will only appear if the licence option, "Save Plan for Variance Reporting" is enabled.

This function allows the saving of the plan from a specific, defined date and replaces the existing Variance Reporting functionality. The date can be moved daily, weekly or monthly so that changes to the plan can be monitored. The variance can be reported using the Variance Loop and the fields that you require start with "Retained…" Please see here (see: Functionality > Save Plan) for an example.

Two "Series" of a saved plan can now be saved, for example a weekly one and a monthly one.

Keyboard = none

Show cover

If an event has been nominated as "Special" via the Framework dialog, the use of the F3 key will result in a colour change to the strip which has an event marked as special. This will notify the planner that the particular special event has either been completed or has still to be completed.

Keyboard = F3
