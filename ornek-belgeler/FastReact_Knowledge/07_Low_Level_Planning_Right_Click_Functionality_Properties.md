# Main Menu - Low Level Planning - Right Click Functionality - Properties

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Low Level Planning > Right Click Functionality > Properties
**Index keywords:** Properties

---

When selected the dialog screen below will open.

This screen gives the planner information relating to the selected STRIP on the planning board.

Within this screen the transport method and strip efficiency can be changed.
