# Main Menu - Help - About

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Help > About
**Index keywords:** Help

---

## About FastReact

This dialog displays information about the current FastReact program including its version and database version number.

The dialog will also give information about memory usage and the number of FastReact items (orders, product, materials and strips).

### General

**Logged on users (button):** This button display all the users who are logged onto the FastReact system at that time.

**Analysis (button):** This button will analyse the current system and produce a report based upon its finding.

> **Note:** This will only be available to Fast React representatives with the correct Dongle type.

**Collab Log (button):** This button display the log of Collaborative planning. The button will only be active if Collaborative Planning is enabled.

**Log setup (button):** This button display all the users who are logged onto the FastReact system at that time.

### Licence details

This tab will enable the user to view and change the system licence configuration.

> **Note:** Configuration can only be changed via Fast React Systems Ltd.

**Load… (button):** This button is used to load the new FRL licence file supplied from Fast React Systems Ltd.

**Save… (button):** This button will save the currently displayed licence configuration to an FRL file.
