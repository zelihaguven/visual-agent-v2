## FastReact Remotes

### FR Remote Version 1.

Previously known as FastReact RAS (Remote Access Services), FR Remote allows production plans and event diaries to be packaged up and emailed to remote sites and users. These packages are opened by a special viewer (FRREMOTE.EXE), which allows the package information to be decrypted and viewed in a variety of ways. Additionally, recipients of the packages can feed back, via E-mail, to the host FastReact system details of actual production and event progress.

A pair of menu options, one to prepare and send the packages, the other to receive and incorporate the returned packages, supports this functionality. These options are supported on the following menu options.

Tools - Remote data requests

Tools - Process remote response

### FR Remote Version 2.

FastReact Remote version 2 offers a view which shows Critical Path events and also includes production operations. The Remote view offers the user the option to sort the board in the same manner as the Critical Path planning board.

The Remote has the ability to mark Critical Path events and operations as 'done' in FastReact, but where these Critical Path events and operations are linked the Remote will only show a single activity which combines the properties of both. As such updates will be allowed as dates and quantities.

The Remote has a drop down style of board which shows an entire order as a single strip with Critical Path extent, schedule and transport all in a single colour. This view can be sorted by either 'Start Date' or 'Earliest Event'.

This version of FR Remote allows the user to enter 'Expected' and 'Completed' dates for all the events, including any production stages, if the user has rights to do this. It also allows the user to skip and enter notes, if required, against each event.
