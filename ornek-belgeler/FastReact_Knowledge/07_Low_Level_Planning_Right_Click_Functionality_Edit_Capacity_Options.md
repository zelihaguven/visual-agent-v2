## Edit capacity options

[Screenshot: LL RC Edit Cap options]

This option is used to open the Capacity dialog where the user could change the Row capacity for a set period.

There are two different dialogs available depending upon how the Row that the strip is on has been setup.

### 1. Row has a set capacity.

[Screenshot: LL RC Edit Cap options]

Here the user can manually change the capacity for the whole Row for a set time scale.

### 2. Capacity set by strip.

[Screenshot: LL RC Edit Cap options]

Here the user cannot set the Row capacity as this is Varied by strip.
