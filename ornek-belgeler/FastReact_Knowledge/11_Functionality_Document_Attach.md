## Document Attach

The Document Attach functionality allows users to attach various documentation to a product and/or an order. This functionality is particularly useful in the case of design briefs.

**Document attach (button):** - [Icon: Document1 Attach] Document attach button.

This functionality can be found on the Products and Orders dialogs. It is a licensable option that can be turned on, on the users licence file.

Each product/order can have multiple documents attached. The documents that have been attached to a product/order can be located anywhere on the network. However, once they have been attached, a link to the document is held at a central location. This location would have been setup during the setup of the FastReact system. For more information see here (see: Main Menu > Setup > Configure > General).

## Document manager

This dialog allows the user to save documents against a particular product/order.

#### Manage documents

This dialog enables the user to browse the network and select documents to attach to a particular Product/Order. Each document can be attached to many Products/Orders, and each product/order can have many documents.

**The tree view:** Upon opening this dialog the user will be faced with a tree view of their network. Drilling down into the folders on this view will produce a list of all files within the folder.

**File list:** This list will be displayed on the left of the dialog. It is from this is that the user can select documents to attach to the product/order.

Right clicking on the document in the file list will rotate its status from 'attached', to 'public', to 'delete from Order/Product'.

> **Note:** Deleting the document from the order/product does not delete the document from the network. It is only the link in the Doc Attach file that is deleted.

Save

| | - Save button. |
|---|---|

This button will save a link to all the attached documents. This link will be saved in the specified place.

Attached list

| | - Attached list button. |
|---|---|

This button will allow the user to see all the documents that have been saved against that Product/Order. From here, right clicking on a document will change the status to 'Public'. This is required if these documents are to be available to FR Remote users.

### View

**Documents for:** This is the order or product name for which the listed documents are valid.

**Location:** This is the location of the file containing the links to all the attached documentation.

**File name:** This is a list of all the attached documents for the particular order or product. Double clicking on a document will open that document.
