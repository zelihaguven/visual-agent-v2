# Functionality - Pop Out Strip Hints

**Source:** FastReact Help (version 4.44) — Functionality / concepts
**Menu path:** Functionality > Pop Out Strip Hints

---

## Pop Out Strip Hints.

Functionality exists in Evolve/Align from 4.39 to greatly enhance the Strip display hint within both the High and Low level Planning Boards. This Pop Out Strip Hint functionality allows users to configure the data that they wish to be displayed on their view of the Planning boards.

For example:

[Screenshot: PopOutResults]

### Configuration

To turn on this functionality navigate to **SETUP - CONFIGURE - PLANNING**

[Screenshot: PopOutConfig]

Open the Planning configuration dialog and scroll down the Options list to the Option, **Enable pop out strip hint**. Turn this on

[Screenshot: PopOutConfig]

> **NOTE:** Notice that when this Option is enabled that the Strip hints section becomes inactive. The Pop Out Strip Hints option and Strip Hints are mutually exclusive.

### Setting up the Pop Out on the Users Planning Board

Return to the Planning Board, either High or Low level as the Pop Out will be the same on both Planning Boards for the User being set up.

There will be a new icon on the Planning Board menu bar:

[Screenshot: PopOutUser]

This is the Pop Out Strip Hint configuration button. Click on this button and the Pop Out Strip Hint dialog will appear. When it is first used the dialog will be empty and require User configuration:

[Screenshot: PopOutUser]

Click on the **Configure** button to view the available hints. This screen will show the available hints on the left and the selected hints, (what the user sees when hovering over a strip), on the right:

[Screenshot: PopOutUser]

Selecting the **Auto size** option will allow the Pop Out dialog to resize with the data displayed.

> **NOTE:** This User configuration will need to be done for all Evolve/Align Users. But it will allow the User to see data that is pertinent to them

Now on the Planning Board the user will see the data on the Pop Out Strip Hint that they have configured whenever they hover over a strip.
