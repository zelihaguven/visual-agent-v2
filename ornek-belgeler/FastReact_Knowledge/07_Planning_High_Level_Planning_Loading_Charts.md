# Main Menu - Planning - High Level Planning - Loading Charts

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > High Level Planning > Loading Charts

---

## Loading Charts

Also known as the Capacity Display, the loading charts occupy the lower half of the High level plan and show the percentage loading on each of the displayed groups. The loading charts can also be toggled so that they occupy the entire plan or are hidden altogether using the buttons on the tool bar or by pressing the Space key. If you want more detail it can also be switched to show the numeric values behind each of the loading bars.

The load charts have an information scale down the left hand side.

### Information scale

**Group name:** The name of the group is shown in the top left of the panel for each group.

**Section name and colour:** The name of the section to which the group belongs is shown beneath the group name. The colour associated with this section is shown to the left of this. If you have a cascaded system (multiple sections) this can be useful to differentiate between these.

**Capacity (per hour):** To the right of the section name, FastReact shows the capacity (per hour) of the operations that you have flagged as 'Planned' in the Operation configuration.

**Location:** Each planning group has a geographical location. This is shown below the section name.

**Property:** This show the 'Property' that you have associated with the Group as an aid to manual planning in loading new orders where property matching will eliminate groups that cannot handle the new order.

By double clicking in this area, FastReact will show all orders that are planned in the selected group. This provides a very quick way of filtering the planning board to show a selection of orders.

### Loading bars

The main body of the loading chart display shows a series of bars for each planned group. These bars show diagrammatically the loading as a percentage of the periodic capacity so that over and under loads can be easily visualised.

Each bar is constructed from a number of different elements. Some of these are optional as below:

**Load is below minimum value:** Where the percentage load against capacity is below the minimum value that you have defined the bar will be shown in Blue.

> **Note:** The user can define minimum and maximum values in Main menu - Configure - Planning on the Loading bar charts tab.

**Load is between minimum value and maximum value:** Where the percentage load is between the defined minimum and maximum values the bar will be shown in Yellow.

**Load is above maximum value:** Where the percentage load is above the maximum value the load will be shown in Purple.

**Load is over 200%:** In this case the top of the bar cannot be displayed as the percentage scale runs from 0% to 200%. In this case the bar is shown in Red to warn of a serious overload.

### Scrolling

Vertical scrolling of the Loading charts can be achieved in a number of different ways:

- Use the scroll bar on the right of the charts;
- Hold the Shift key down and press the Up and Down keys;
- Hold the Shift key down and use the mouse wheel (if available);
- Hold the Shift key down and press the Home key. This will also scroll horizontally to show the start of the date scale;
- Press the Home key on its own and this will also scroll the Planning board to the top row.

Horizontal scrolling is achieved with the Left and Right arrow keys of by clicking on the scroll buttons on the tool bar. The planning board will scroll as well to show the same period in time.
