## Loading

The diagram below illustrates the Loading of Events, (in aqua) and the available Capacity, (in gray).

[Screenshot: LoadingGraph]

Clicking on any of the aqua coloured Bars on this graph will display the Pre-production events relating to that Bar.

For example, clicking on the Bar dated '11/03/08' will filter the Pre-production planning board to show only all the Events that relate to that time period.

**Expand and Contract (button):** - [Icon: ExpandContract] Expand and Contract visible date scale.

This button will expand and contract the visible date scale of the Loading graph.

**Date scroll (button):** - [Icon: ScrollDates] Scroll through the dates.

This button will allow the user to move forward or backwards in time to view any Loading issues that will happen in the future or have happened in the past. Clicking on the '21' will reset the view to 'Today'.

**Loading/Capacity view (button):** - [Icon: LoadingCapView] Scroll through the dates.

This option will allow the user to choose the view type that they want to see.

**Period range (button):** - [Icon: PeriodRange] Period range for Loading.

This option will allow the user to select the range over which the Loading/Capacity is viewed.

**Find (button):** - [Icon: Find] Find.

This button will display the Find dialog which will allow the user to 'find' particular Events based upon the Find dialog selection criteria.
