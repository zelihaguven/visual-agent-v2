## User Defined Order Status

Extended Order Status allows the users of FastReact to define customised status values to the selected Order.

### Status matrix

#### ID

This is a fixed, unique reference for the Colour and Description of the new, user defined status value.

#### Colour (Click to set colour)

A colour can be associated to a User Status. This makes it easier to identify on the Planning Board under the Status Rotation.

**Description:** A description of the status is entered here.

**Save (button):** This button will save the newly created User Status values.

Warning:-

The Order Status' are position sensitive. Once defined and in use do not move the description to a different ID as existing data will be invalidated. Descriptions may be changed to correct errors as long as the underlying meaning remains the same.
