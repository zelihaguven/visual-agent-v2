# Reference - Importing Data - Descriptor Links

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > Import Data > Descriptor Links
**Index keywords:** Descriptor Links

---

Product Operations may be imported from a file called OPNLNKS.txt or OPNLNKS.csv.

The following fields may be imported. Essential fields are shown in bold.

| Field Name | Type | Description |
|---|---|---|
| **D.OPN** | T30 | The operation's external reference. |
| D.NAME | Date | The Descriptor Code/Name. |
