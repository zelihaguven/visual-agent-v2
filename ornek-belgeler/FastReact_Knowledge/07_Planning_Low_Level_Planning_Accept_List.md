# Main Menu - Planning - Low Level Planning - Accept List

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > Low Level Planning > Accept List
**Index keywords:** Accept List

---

## Accept list

The load list will show orders still to be planned, even users who do not have rights to plan orders will be able to view the load list, but in order to see this list the orders must first be accepted, by the Planner to the Low Level.

### Select orders to accept

The list contains a list of orders that have been planned on the High level planning board, (if the High Level Planning Board is part of the FastReact Licence options) and are now ready to be accepted, by the planner, to the Low Level Board. The list contains the following columns of information:

**Accept:** A check box is provided against each order on this list. This allows the Planner to select individual orders in any sequence, whilst leaving unselected orders on this accept list.

**Order:** The order reference is preceded with a small rectangle showing the colour (if any) associated with this order. This followed by the order reference itself. There may be several entries in the list for the same order if that order has multiple deliveries. For new orders the colour of this entry will your normal Windows colours (e.g. black on white). However, in systems which have Low level planning, a red order reference will show you that the order had been allocated to a Low level planning board, but that planner had rejected the order.

**Product:** A rectangle showing the colour associated with the Product type for this product, followed by the Product reference for the order.

**Product type:** The product type associated with the product above.

**Customer:** A rectangle showing the colour associated with the Customer followed by the Customer reference.

**Delivery:** The delivery date for this part of the order. Note that an order can have multiple deliveries.

**Quantity:** The balance to make of this delivery, bearing in mind that an order can be in the load list even if production has already started.

**Description:** This is the description of the Order or the Product. You can decide which you want to show in the planning board configuration.

### Accept selected orders

This option will only accept the orders that have been checked as Accept and ignore the unchecked orders. The checked orders will disappear form the accept dialog and will appear on the Low Level Load List.

### Accept all orders

This option will unilaterally accept all of the orders in the accept dialog without exception.

### Print

The Accept list can be printed.

### Setup

The Accept list can be altered to include User Defined Fields.
