## Automated Host Order Substitution

This dialog shows the Planner all the available Orders that can be substituted. The planner can then decide whither or not to apply these substitutions via the Apply button.

### Substitutions

##### Viable Orders:

This is a list of all Host Orders and their corresponding Substituting Orders that are available for the planner to automatically substitute.

##### and Status:

These options allow the user to select a status type to apply the Substitution to.

##### Calculated Substitutions:

This list shows the Planner the calculations and where the substituted Orders will be planned based upon the Viable Orders list.

**Apply (button):** This button will apply the calculated substitutions and automatically process the orders.

#### Information:

This text box will list the processes that Evolve/Align runs through when checking and substituting Orders.
