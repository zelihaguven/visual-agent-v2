# Main Menu - Setup - Planning - Options

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > Planning > Options

---

## Planning Board Options

### Auto load settings

FastReact can auto load orders onto the Low Level Planning Board directly from the Accept Orders to Load List box.

#### Autoload by matching order property

It does this by matching user defined values for each order with the Property associated with each planning board row. Select the user defined order field to match in this list box and click Update. The auto load option may be disabled by selecting (none).

#### ------ Or ------

**Autoload by planning row (button):** With this option enabled the planner can set the Planning Row on which to load strips within the Grid Style Low Level Load List.

> **Note:** This will not work if using the traditional Load List style.

**Update (button):** Once the UDF has been matched this button will enable the auto load function.

### Alternative strip display

The details shown on the planning board strips can be rotated through various alternatives. One of these alternatives is to show a user defined field value, selected from Order, Product or Customer user defined fields.
