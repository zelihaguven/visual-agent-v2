# Main Menu - Tools - Receive Collaborative Package

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Receive Collaborative Package
**Index keywords:** Receive Collaborative Package

---

## Receive Collaboration Package

This dialog will initiate the amalgamation of the Host and Remote systems.

### Check for packages

**Mail account to check:** This is the designated collaboration email account to which the returned packages are sent.

**Extract to folder:** This is the folder, which was defined during setup, that the returned collaboration data will be extracted to.

**Check for mail (button):** This button will check the designated collaboration email account for returned packages.

**Use local folders (button):** This button will use the extracted files in the local folder.

#### Progress

The progress of the above two buttons will be displayed in this text box.

**Process All (button):** This will initiate the collaboration between the Host and Remote(s) sites.

### Configure

#### Process packages and conformation handshakes.

**From email:** This option will use email to process the incoming packages and handshake files.

**From folder:** This option allows the use to browse for a local folder in which to process incoming packages and handshake files.

#### Options

**Allow group data to be imported:** This option will, in the receiving system, allow the collaborative partners group data to be imported in to it.

**Allow group consolidated capacity to be imported:** This option will allow the receiving system to overwrite its capacity with the capacity from the collaborative partner.

**Allow row and buildup data to be imported:** This option will allow the receiving system to import row and build up data from the collaborative partner.

**Allow new orders to the plan of the consolidated group:** This option will by-pass the collaborative partners High Level board and place the Order in the Low Level Load List of the Collaborative Group

**- Default to 'Plan in Group' of order:** Used in conjunction with the above option, this option will use the Plan In Group field to automatically assign the Order to the correct Low Level Load List.

**Save (button):** This button will save the details selected above.
