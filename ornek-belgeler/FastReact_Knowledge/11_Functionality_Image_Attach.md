## Image manager.

The Document Attach functionality allows users to attach various documentation to a Product. This functionality is particularly useful in the case of design briefs.

**Image attach (button):** - [Icon: Image Attach] Image attach button.

This functionality can be found on the Products dialog. It is a licensable option that can be turned on, on the users licence file.

Each product can have multiple images attached. The images that have been attached to a Product can be located anywhere on the network. However, once they have been attached, a link to the image is held at a central location. This location would have been setup during the setup of the FastReact system.

This dialog allows the user to save images against a particular product.

#### Manage images

This dialog enables the user to browse the network and select documents to attach to a particular Product. Each image can be attached to many Products, and each Product can have many images. However, the only image that will be seen on the planning boards will be the default image. The default image will normally be the first image saved against the Product.

[Icon: Func Image Attach]

##### Add new image

**Name:** This is the name of the image file.

**Image file location and name (button):** Clicking on the browse button will allow the user to browse to the location, either locally or on a network, where the image is located.

This field will hold the path details to this image.

A thumbnail of the attached image can be seen to the right of this path.

**Save (button):** This button will save a link to all the attached documents. This link will be saved in the specified place.

Attached list

##### Select an image to manage

###### Image list

This is a list of all the images attached to the product. Selecting an image name from this list will allow the user to either rename it or delete the image link.

**Enter a new name:** To rename the image, first select the image name from the list and then type in the new image name in this field.

**Rename (button):** Clicking on this button will rename the selected image to the new image name as typed in the 'Enter a new name' field.

**Delete link (button):** This button will delete the selected images thumbnail and link. It does not delete the actual image.

### View

[Icon: Func Image Attach View]

###### Product

This is the product name for which the listed images are valid.

**Click to make default image (button):** This button allows the user to select a different image from a list which will then become the default image. This default image will then be seen on the Planning Board when the planner 'hovers' the mouse over a order which has this product as its product.

###### Image list

This is a list of all the attached images for the particular product. Double clicking on a document will open that document. Clicking on an image in this list will show it in the image view area next to this list.

Warning.

The thumbnail image generated on the Planning Boards will not be altered if the path to the actual image or a new image is added. To alter the path or change the thumbnail requires the user to use the Manage Image dialog on the Products Add/Amend dialog.
