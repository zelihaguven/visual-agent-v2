## Notes

FastReact can provide an audit trail of changes and updates to orders and products allowing you to see changes in chronological sequence and the person responsible for making the changes.

Additionally, user notes can be added to these same objects and, from the planning board, strip notes can be added. User notes can be deleted but only be the user who created them.

Notes can be viewed in their entirety or filtered to show a sub set of notes. Thus views of changes, production updates, critical path updates etc., can be seen.
