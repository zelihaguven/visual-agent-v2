# Reference - General - Drop Down Row Display

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > General > Drop Down Row Display

---

## Orders Rotation

[Screenshot: PB Order Rotation]

- [Icon: Ref Strip Colour Explained] Strip colour definition.

- The first of the four blocks defines the strip colour as its displayed on the board.
- The second block shows the text colour of the strip on the board.

Black text = No learning curve.

Red text = Learning curve.

- The third block represents the text background colour. This will appear green if the strip is planned at a lower efficiency then defined on the strip colour setup.
- The fourth block represents the strip boarder.

A black boarder = No WiP issues

A red boarder = WiP issues.

## Product details / Order colours

[Screenshot: PB ProductDetails Rotation]

The blocks of colour all represent the same as for the Order Rotation. The only difference here is that the Product details and the Order colours are displayed on the strip.

## Product Rotation

[Screenshot: PB Products Rotation]

The blocks of colour all represent the same as for the Order Rotation. The only difference here is that the Order Code has been replaced by the Product Code on the strip.

## Product Type Rotation

[Screenshot: PB ProductTypes Rotation]

The blocks of colour all represent the same as for the Order Rotation except the first block which represents the Product Type colour.

## Customer Rotation

[Screenshot: PB Customers Rotation]

The blocks of colour all represent the same as for the Order Rotation except for the first block which represents the Customer colour.

## Delivery Rotation

[Screenshot: PB Delivery Rotation]

The blocks of colour all represent the same as for the Order Rotation except for the first block which represents the Delivery Month colour.

## Colour Rotation

[Screenshot: PB Colour Rotation]

The blocks of colour all represent the same as for the Order Rotation except for the first block which represents the Order colour if set on Orders Add/Amend dialog.

## Materials Rotation

[Screenshot: PB Materials Rotation]

The blocks of colour all represent the same as for the Order Rotation except for the first block which represents the Materials colour. For details of the materials colours please see here.

## Reservation

[Screenshot: PB Reservation Rotation]

The blocks of colour all represent the same as for the Order Rotation. The labels on the strip relate to the Reservation reference.

## User defined Rotation

[Screenshot: PB UDF Rotation]

The blocks of colour all represent the same as for the Order Rotation.

## Event Status

[Screenshot: PB Event Status Rotation]

The blocks of colour represent the Event status colour as defined on the Events setup dialog.
