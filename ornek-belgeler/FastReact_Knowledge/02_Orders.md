# Main Menu - Orders

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Orders

---

The following is a list of options available under the Orders option on the Main Menu:

- Add / Amend
- Manage multi-part orders
- Allocate to plan
- Transfer
- Change availability
- Notes
- Purge
- Grid style entry

- Flows
- Master flows
- Purge flows

- Substitute Host Order (Automated)

- Retain event target dates
