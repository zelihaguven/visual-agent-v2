# Main Menu - Reports - Printing Options

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Reports > Printing Options

---

When Selected the following dialog box will be displayed.

[Screenshot]

| Option 1 | This shows how many pages are in the report, in the picture above the report is six pages long and two pages wide (twelve pages in total). You can choose not to print certain pages by clicking on the relevant box. RED = Not printed GREEN = Printed |
|---|---|
| Option 2 | By ticking this box the report will print in reverse order. |
| Option 3 | If you click on " + " all pages will be selected to be printed. If you click on " - " all pages will be skipped. |
| Option 4 | Here you can select the first " x " pages of the report. |
| Option 5 | Allows you to print multiple copies of the report. |
| Option 6 | Print or cancel the report. |
