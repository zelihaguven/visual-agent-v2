# Main Menu - Materials - Stock

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Materials > Stock
**Index keywords:** Reservation, Stock

---

## Materials Stocks

This option allows the user to manually enter or adjust stock.

### Material Stocks

**Material reference.:** This is the name of the material that has already been entered into FastReact. Use the drop down button to select the required material or begin typing the material reference to use the incremental search facility.

**Supplier:** This is the name of the material supplier that has already been entered into FastReact. Use the drop down button to select the required supplier.

**Location:** This is the location of the material warehouse where the available stock is. Use the drop down button to select the required location.

**Reservation:** This option is available when the Reservation Licence option is enabled. This field is a user defined link between the Order and the Material Stock.

**New stock quantity:** Enter here the total available stock for the selected supplier and location.

**Adjust quantity by:** You can adjust the available stock quantity in this field, to increase by 100 type 100 to decrease by 100 type -100.

#### Stocks

**Current stock:** This shows the amount of stock held against the material based upon the supplier and location.

**Received to date:** This shows the amount of stock received to date for a particular material based upon the supplier and location.

**Lead Time:** This field will show the lead time for the current material based upon supplier and/or location.

**Constraint:** This is used in conjunction with APS.

**Update (button):** This button will insert or update the current material stock.

**Expand dialog button:** - [Icon: Option] View material at all Locations for all Suppliers.

This button expands the dialog in order to show a list of stock for the current material. This list will include all locations and suppliers for the current material.

### Transfer stock

**Material reference.:** This is the name of the material which will have its stock transferred.

#### Stock to transfer

This is a list of all the Stock available under the selected Material reference.

**Quantity to transfer:** Enter the amount of stock to transfer.

#### New destination

**Suppler:** Select the Supplier name that the stock will be transferred under.

**Location:** Select the Location name that the stock will be transferred to.

**Reservation:** Select the Reservation ID that the stock will be transferred to.

**Update (button):** This button will insert or update the current material stock.
