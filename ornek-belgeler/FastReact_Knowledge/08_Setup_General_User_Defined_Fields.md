## User Defined Fields

*Context: Main Menu > Setup > General > User Defined Fields › User Defined Fields*

User defined fields allow for the configuration of additional information associated with Orders, Products and Materials allowing the user to add their own specific data to these records. This data is in the form of text entries for flexibility, financial data, which will accept floating point numeric data, can also created for Orders and Products.

User defined fields are especially useful in that they may be used to filter and sort reports according to company specific criteria thereby offering greater flexibility.

Each field size can be altered via the configuration menu option.

### Define

*Context: Main Menu > Setup > General > User Defined Fields › User Defined Fields › Define*

#### Select a UDF type to change

*Context: Main Menu > Setup > General > User Defined Fields › User Defined Fields › Define › Select a UDF type to change*

**Orders:** This option allows the user to enter a list of Order related User defined fields. Select the Order from the list and type in the name in the column labelled 'Enter field name'.

**Products:** This option allows the user to enter a list of Product related User defined fields. Select the Product from the list and type in the name in the column labelled 'Enter field name'.

**Products types:** This option allows the user to enter a list of Product type related User defined fields. Select the Product type from the list and type in the name in the column labelled 'Enter field name'.

**Customers:** This option allows the user to enter a list of Customer related User defined fields. Select the Customer from the list and type in the name in the column labelled 'Enter field name'.

**Order financial values:** This option allows the user to enter a list of Order financial values User defined fields. Select Order financial values from the list and type in the name in the column labelled 'Enter field name'.

**Product financial values:** This option allows the user to enter a list of Product financial values related User defined fields. Select Product financial values from the list and type in the name in the column labelled 'Enter field name'.

**Materials:** This option allows the user to enter a list of Material related User defined fields. Select Materials from the list and type in the name in the column labelled 'Enter field name'.

**Flows:** This option allows the user to enter a list of Flow related User defined fields. Select Flows from the list and type in the name in the column labelled 'Enter field name'.

> **Note:** This field will only be available if you have flows enabled on your licence.

**Plan Row:** This option allows the user to enter a list of Plan Row related User defined fields. Select the Plan Row from the list and type in the name in the column labelled 'Enter field name'.

**Plan Group:** This option allows the user to enter a list of Plan Group related User defined fields. Select the Plan Group from the list and type in the name in the column labelled 'Enter field name'.

**Forecast:** This option allows the user to enter a list of Forecast related User defined fields. Select the Forecast from the list and type in the name in the column labelled 'Enter field name'.

**Design / Other:** This option allows the user to enter a list of Design related User defined fields. Select the Design / Other from the list and type in the name in the column labelled 'Enter field name'.

> **Note:** These Design / Other fields will be used to populate the Buy details from the Range hierarchy. The sequence and count of the first values must match the range hierarchy exactly. Also these UDF values will be copied to the first order UDFs in the defined sequence.

**Enter field name:** New User defined fields are entered here or one can be selected from the list bellow. The field name may be up to 15 characters long. Fields can only created or deleted here. If a User defined field is deleted, then all data associated with it within the Order, Product or Material records will also be deleted.

**Enter a new name:** This option allows you to rename a selected User defined field. Select the required User defined field from those that have previously been entered and type a new name in the field labelled 'Enter a new name'.

**Rename (button):** This button will rename the selected UDF.

**Collaboration ID:** When Collaboration has been enabled on the system, this option will appear. The UDFs that will be collaborated between the Host and the Remote systems MUST have the same ID set here.

**Delegate to remote:** When Collaboration is enabled, and the UDF is to be collaborated, the user can assign responsibility for that UDF to the collaborative partner.

**Update (button):** This button will update the collaborated UDF.

**Insert (button):** This button will insert a new UDF.

**Delete (button):** This button will delete the current UDF.

**Enter a new name:** Once the UDF that has to be renamed has been selected, the new UDF name can be entered here.

**Restrict data entry input to:** This option is only available when entering Product UDfs and, at present, only references Plan Groups. The user may restrict the Product UDF to a list of Groups. This will appear as a drop down list on the Products UDF dialog.

**Rename (button):** This button will rename the UDF.

### History

*Context: Main Menu > Setup > General > User Defined Fields › User Defined Fields › History*

If the Product History opting is enabled then the user can select a defined UDF to save along with the Product History. Only one UDF from Orders and one UDF from Products may be chosen.

#### Select Order UDF to be saved with product history

*Context: Main Menu > Setup > General > User Defined Fields › User Defined Fields › History › Select Order UDF to be saved with product history*

This is a list of all the available Order UDFs. Highlighting one will select that UDF to be saved with product history.

#### Select Product UDF to be saved with product history

*Context: Main Menu > Setup > General > User Defined Fields › User Defined Fields › History › Select Product UDF to be saved with product history*

This is a list of all the available Product UDFs. Highlighting one will select that UDF to be saved with product history.
