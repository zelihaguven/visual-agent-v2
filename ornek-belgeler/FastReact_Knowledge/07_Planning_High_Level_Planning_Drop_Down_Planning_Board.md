## High Level Drop Down Planning Board

The revised Critical Path now comes with the option to view the critical path events from the High Level Planning Board. The Critical Path can be viewed on the High Level Planning Board when it is enabled via the Sort icon on the High Level Planning Board menu.

### Drop Down High Level Pre-production

The High Level Planning Board can be used to view critical path events.

#### Pre-production (Critical Path)

The option which allows the user to configure the Drop Down High Level planning board enables the Planner to have access to Production as well as Pre-production elements directly from the High Level Planning Board.

For example,

[Screenshot: HL Drop down board]

From here the planner can, via the right click function, call the Update dialog in order to either update individual event dates, complete events or skip events.

The Planned Operation, "Start Cut", is also included in the Drop Down view and has the amount of Production made and the Total amount required.
