## Add & Amend

*Context: Main Menu > Products > Add and Amend › Add & Amend*

To be able to use FastReact the user must enter a product against each manufacturing order. The user can create, delete, modify, copy and rename products all though this single menu option. Security rights applied to the User group to which the user belongs may disable or hide certain options. Other options may not be enabled in the FastReact configuration.
