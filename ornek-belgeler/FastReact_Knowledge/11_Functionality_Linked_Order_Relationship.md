## Linked Order Relationship.

This option will only appear if the Prior / Next option is licenced on the user licence file. With this option licenced, clicking on the Linked order relationships will result in the dialog below. These relationships are setup on the Orders Add/Amend dialog in the Prior and Next fields.

Linked order relationships modified to show the Orders Planned status via a traffic light icon:

[Screenshot]

The icon appears on the top right hand side of the Linked Orders dialogue and each light colour represents:

- A RED traffic light - means that the Order is completely unplanned
- A YELLOW traffic light - means that the Order is partially planned
- A GREEN traffic light - means that the Order is fully planned

Also shown on the Linked Order dialogue will be a break down of the Planning board(s), Group(s) and Planned/Made Quantities(s), each order show contains a breakdown of Planning board / Group / Quantity

A dash '**-**' represents any unset/unplanned element of the Order.

The above dialog is a graphical representation of the relationships between orders F_1000, P-130::PUC and T-190 as defined on the Orders Add / Amend dialog.
