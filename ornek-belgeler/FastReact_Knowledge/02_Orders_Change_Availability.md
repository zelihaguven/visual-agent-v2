# Main Menu - Orders - Change Availability

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Orders > Change Availability
**Index keywords:** Change Availability

---

## Changed Availability

### Changes

This dialog enables the user to change the date that the production update will be ready.

**Order reference:** This is the order number/name.

#### Change availability of existing production updates

This table will hold all the updates for a particular order.

**Update Date:** This is the selected date chosen on the Update Progress dialog. Under normal circumstances this will be the current day's date.

**Group:** The group and the Planning Board to which the order is on.

**Quantity:** The update quantity.

**Original Date:** This is the date that the updated amount will be available either to the customer or to the factory, based on the original update date described above, and takes into consideration transport, standing time, offsets, etc

**Revised Date:** The new date (manually entered) in which the items will be available either to the customer or to the factory.

**Update (button):** Initiates the change.
