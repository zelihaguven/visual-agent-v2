## Row scale strip list

### Low Level Planning Board

If you click on the status column on the Row scale, FastReact will display a list of strips on the clicked row.

The list shows details of strips including:-

- Start date and time
- Order reference
- Product reference
- Customer reference
- Total quantity on the strip

Following this FastReact will show the status of each strip:-

**Early days:** This is the number of days early (in red) that the strip is planned relative to the critical path timetable for that order.

**Delivery:** This is the delivery date.

**Late days:** (the number of days late compared to the delivery date. Note that the number will be negative and shown in red for late strips, and positive and black if planned early compared with the delivery date)

**Late qty:** This is the quantity on the strip that will miss its delivery date. This value will be zero if planned early to delivery

You can sort the table by clicking on a column heading; clicking again will reverse the sort sequence.

The table is also resizable so you can scale it to fit your data.
