# Main Menu - Tools

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools

---

The following is a list of options available under the Tools option on the Main Menu:

- Import data
- Remote FOB / CIF
- Remote Planning
- Process Remote Responce
- Request for quotation
- Distribute remote plan
- MPS - Plan Line
- Retrieve distributed plan
- Remote data requests
- Return plan to host - Plug out system only
- Send collaborative package
- Receive collaborative package

- 'What If?' planning
- Populate test database
- Email database to ...
- Utilities
- Review change log

- Archiving

- Archive Orders
- Un-archive Orders
- Archive Products
- Un-archive Products

- Batch Tickets
