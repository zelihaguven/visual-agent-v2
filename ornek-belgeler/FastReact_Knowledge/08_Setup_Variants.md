## Variants

Variants are used in Costings, Range Planning and Designs. Up to 5 variants can be defined.

### Variant names

#### Variant matrix

This is a list of the defined variants and their types.

**#:** The Variant number or ID.

**Variant:** The Variant name.

**Type:** The Variant type. There are two types of Variant Type:

- Pick from list : The use will pick the variant from a predefined list.
- Free form : The user will enter a free text variant.

### List values

#### Select variant

This is a list of the defined Variants.

#### Current values

This is a list of the currently available values for the selected Variant.

**Value:** The new value to be added to the list for the selected Variant.

**Add (button):** This button adds the new variant to the list.

**Delete (button):** This button will delete the selected value from those available to the Variant.
