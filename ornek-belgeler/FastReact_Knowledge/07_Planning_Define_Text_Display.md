**Menu path:** Main Menu > Planning > Define Text Display
**Index keywords:** Define Text Display

## Define Text Display

Text Display can be added to both the High Level, Low Level and Critical Path Planning Boards.

To add text display right click on the a planning board and choose 'Define Text Display'.

- [Icon: Text define] Define Text Display.

### Available data

From the resulting dialog add new text to the planning board by double clicking on the available data field you would like to show.

### Displayed data

This field on the dialog will hold the data which will be displayed on the Planning Board.

### Column width

The width of each data entry can be adjusted and set using this column.

**Set as default (button):** This button will make the data selected a permanent feature for all users viewing the particular board.

> **Note:** The Define Text display can be unique for each user, unless the Set as default button is clicked.

**Update (button):** Once you have done this press the update button and close the dialog box. The selected data will now appear on the Planning Board.
