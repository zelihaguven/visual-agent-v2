# Main Menu - Tools - Import Data

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Import Data

---

## Import data

FastReact can import data from files generated by your business system. All data that may change on an ongoing basis can be entered into FastReact in this way avoiding the need for users to enter the same data twice. The import process is very simple from the user's perspective; just click on the Start button and wait until it has finished. FastReact will generate logs of any problems encountered in the import process and can generate a log of successfully imported data. Only data that is static in nature or part of the system configuration cannot be imported.

### Import data

Imports can be started manually through this menu option, or can be triggered automatically to run at specified times of the day and days of the week.

A technical explanation of the import procedures may be found in the Reference Section.

**Skip MPS:** By checking this option the Import procedure will effectively miss out the MPS calculations.

**Import (button):** This button will start the importing process.

### Reports

After an import has taken place this tab will be displayed. Under this tab the user can get a report of the status of the import.

The option for reporting are:

**Imported:** This report details all of the successfully imported records.

**Fatal errors:** This will report major faults within the import files. The import process will stop if a fatal error is encountered.

**Warnings:** This will report those records that FastReact was unable to import and give a reason why.

**Debug output:** This report will point you in the right direction on how to rectify your import file. This would normally be used by the FastReact installation team to get the import file format right and once settled the Debug logging may be disabled.

### Print

The logs may be printed.
