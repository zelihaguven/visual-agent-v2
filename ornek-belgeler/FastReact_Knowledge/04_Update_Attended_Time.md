# Main Menu - Update - Attended Time

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Update > Attended Time
**Index keywords:** Attended Time

---

## Attended time

This licence option allows the users to record the actual time that each row or group worked per day or week.

### Attended time

**Select week ending date to update:** The user can select the week ending date from the drop down calendar.

###### Week end day

This is the system defined day as set under Setup - Configure - Planning - Calendar

##### Attended time matrix

This matrix lists the Group, Row and days, if configured by Row and Daily, for the attended time.

**Group:** The names of all the Groups defined in FastReact.

**Row:** The names of all the Row defined in FastReact.

**Days:** The names of the days of the week, starting with the first working day as defined in FastReact.

##### Attended time

Manually attended time can be entered here. Data is entered in hours.

> **Note:** Although Attended Time is entered in Hours it is reported in minutes.

**Update (button):** This button will update the event with the inputted Reason for failure.

#### Configure

**Group level updates only:** Instead of Row Attended Time figures the user may want to enter Group level Attended Time data.

**Enter weekly totals:** Instead of daily Attended Time figures the user may want to enter weekly level Attended Time data.
