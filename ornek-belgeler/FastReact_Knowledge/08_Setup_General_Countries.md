# Main Menu - Setup - General - Countries

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Countries
**Index keywords:** Countries

---

## Country definition

This dialog is a list of countries and duties.

### Countries

**#:** This is a unique, FastReact generated, incremental number.

**Country:** This is a list of user defined Countries.

Warning:

Country names are position sensitive in this table. Do not move countries to new rows, but names can be edited to correct spelling mistakes.

### Duty

**Counrty:** This is drop down list of the previously created Countries.

#### Product Type / Duty matrix

**Product type:** This is a list of Product Types.

**Duty:** A user defined value can be entered against each Product Type for each Country.
