# Reference - Importing Data - Material Allocation

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > Importing Data > Material Allocation
**Index keywords:** Material Allocation

---

Material allocations may be imported from a file called MATALLOC.txt or MATALLOC.csv.

The following fields may be imported. Essential fields are shown in bold.

| Field _ Name | Type | Description |
|---|---|---|
| **MA.ORDER** | T30 | The order number that a material is to be allocated to. |
| **MA.MAT** | T60 | The material code. |
| **MA.QTY** | Integer | The quantity of the material and reference that is to be allocated to an order. |
| MA.REF | T128 | The material reference for the allocation. |
