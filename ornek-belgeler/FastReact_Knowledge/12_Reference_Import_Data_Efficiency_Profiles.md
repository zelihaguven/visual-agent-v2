# Reference - Importing Data - Efficiency Profiles

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > Import Data > Efficiency Profiles
**Index keywords:** Efficiency Profiles

---

Efficiency details may be imported from a file called EFFICIENCY.txt or EFFICIENCY.csv

The following fields may be imported. Essential fields are shown in bold, other fields may be omitted.

> **Note:** Efficiencies must be grouped EF.NAME.

| Field Name | Type | Description |
|---|---|---|
| **EF.NAME** | String | The name of the Efficiency Profile to be imported. |
| **EF.PTYPE** | String | The Product Type for the Efficiency. |
| **EF.EFFICIENCY** | Integer | The Efficiency value. |
