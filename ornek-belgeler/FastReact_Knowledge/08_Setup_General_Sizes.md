# Main Menu - Setup - General - Sizes

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Sizes
**Index keywords:** Sizes

---

## Size Definitions

This menu option will only be visible if it is enabled under the terms of the licence agreement. If it is enabled at least one size name must enter otherwise the user will not be able to create orders of products which both rely on size details.

### Define

**Enter size name to insert:** Enter a unique size name to add to the list. Size names may be up to 25 characters long. There is no defined limit to the number of size names you can create, however, if the list is limited then the operation of FastReact will be easier.

> **Note:** The sizes will be displayed by FastReact in alphabetical sequence, however, you can override this behaviour by prefixing size names with ’01’, ‘02’, ‘03’ etc. FastReact can be configured to hide these sequence characters, see Main menu - Setup
- Configure - General in the Options list of the Default tab.

> **Use a tilde "~" to separate sequence characters:** The use of the "~" tilde before the sequence character(s) will hide this character(s). The tilde is used in this instance because sizes can also be numbers.

For example, 01 Small will appear as 01 Small in FastReact however, ~01 Small will appear as Small in FastReact. For numbers 01 1 will appear as 01 1 and ~01 1 will appear as 1.

**Size list (double click to select for deletion):** This shows those sizes that you have already created. Double click on one to select it so that it can be deleted. FastReact’s referential integrity will prevent deletion of sizes that are attached to orders or products.

**Label for "no size" (saved automatically):** This field allows the user to define a "no size" label.

**Insert (button):** Insert a new size.

**Delete (button):** Delete the highlighted size.

### Size Sets

**Size set:** Enter a unique size set name to add to the list or select a size set from the drop down list to amend.

**Include sizes:** This area holds the sizes, selected from the Available sizes, that make up the particular Size set.

Sizes are added by dragging them from the Available sizes to the Include sizes. Removing sizes is done by dragging the size from the Include sizes to the Available sizes.

**Available sizes:** This list will be populated by the sizes entered on the Define tab. To add a size to a size set drag and drop it from Available sizes to the Include sizes list.

**Save (button):** Save a new size set.

**Delete (button):** Delete the highlighted size.

### Rename

You can rename a size at any time, but bear in mind that size names must be unique.

#### Click on a size to select

This is a list of all the sizes that have been created within the FastReact system.

**Enter a new size name:** Once the size that has to be renamed has been selected, the new size name can be entered here.

**Rename (button):** This button will rename the section.
