## FTP Plug Outs.

Plug out boards can be sent to the remote site via FTP but they cannot be returned this way. This means that FTP option only allows for a one way transfer of data.

This option needs to be turned on in Setup / Email on the Plug Out tab. When enabled a new tab FTP will appear on the planning board setup.

All fields on this tab must be filled in and valid. The Folder field defines where on the FTP site the plug out file must be posted. FastReact will not attempt to create this directory, this is the responsibility of the site administrator.

There is a limit of 247 characters for all of these fields added together.

When a plug out board is sent it will attempt to use this FTP site.
