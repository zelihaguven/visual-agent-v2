## Smoothing

[Screenshot: Smoothing]

This option is will display the Smoothing dialog.

[Screenshot: Smoothing]

This functionality allows the user to smooth the plan after an initial APS rough cut plan, based on demand priority,has been run. The planner is required to enter a number of machines manually and have this number of machines assigned by group by product for the foreseeable future.

The numeric schedule window can be modified to enter a machine count rather than quantity count on an order basis.

This works, by product, across many orders whilst simultaneously showing the effect to the plan line (demand versus supply) in the same dialog. This screen also shows the total machine balance for the group. For number of machine group, how many have been used for suggested and confirmed
