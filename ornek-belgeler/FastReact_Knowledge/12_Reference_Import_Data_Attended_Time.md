# Reference - Importing Data - Attended Time

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > Import Data > Attended Time
**Index keywords:** Attended Time

---

Attended Time details may be imported from a file called ATTMINS.txt or ATTMINS.csv

The following fields may be imported. Essential fields are shown in bold, other fields may be omitted.

| Field Name | Type | Description |
|---|---|---|
| **A.DATE** | Date | The date that the Attended time applies to. |
| **A.GROUP** | T15 | The Group that the Attended time applies to. |
| **A.GROUP_EXTERNAL_ID** | Integer | The External ID of the Group for the planning board Row. |
| **A.ROW** | T15 | The Row that the Attended time applies to. |
| **A.ROW_EXTERNAL_ID** | Integer | The External ID of the planning board Row. |
| **A.MINUTES** | Integer | The Attended Time in minutes. |
