## FastReact translation utility

FastReact provides the option to translate any of the text that appears in the system.

This feature can be used simply to change the terms used in FastReact into more appropriate or familiar ones.

For example, 'Delivery date' could be replaced by 'Shipment' if appropriate.

Alternatively the whole of the FastReact system can be translated into another language.

### Translate

#### Select text to translate

This dialog enables you to select which phrases and text you want to translate. Text which has been translated is shown in red. Original text is shown in green.

#### Special characters

There may be special characters embedded in the text. It is essential that these characters are preserved when translating.

**"&" character:** Phrases or words which include the ‘&’ symbol are menu items where the character following the ‘&’ symbol will be underlined by Windows to create the shortcut to the menu option. These menu options are accessible though the keyboard by pressing Alt and the underlined character.

**"%" character:** Where this character, followed by a 'd' or 's' is included it is an indication that these characters will be replaced by data when the text is displayed. These character pairs can be moved around, but there must always retain the same number otherwise FastReact will not be able to display the data correctly. In this case FastReact will just display the text before the data is inserted so that the user can correct the translation.

**Original text:** This shows the original text that has been selected from the above list.

**Translated text:** Enter the text which will replace the original text.

**Find in original (button):** - [Icon: Find in original] Translate

This button will find the typed text in the original translation file.

This button will find the next typed text in the original translation file.

**Find in translated (button):** - [Icon: Find in transaltion] Find in translated.

This button will find the typed text in the translated translation file.

This button will find the next typed text in the translated translation file.

**First (button):** - [Icon: Find first] Find first.

This button will find the first instance of the translated text.

**Prev (button):** - [Icon: Find previous] Find previous.

This button will find the previous instance of the translated text.

**To translate (button):** - [Icon: Find to translate] Translate

This button scrolls through all the available text that can be translated.

**Next (button):** - [Icon: Find new] Next.

This button will scroll to the next instance of the translated text.

**Last (button):** - [Icon: Find last] Last.

This button will scroll to the last instance of the translated text.

**Save Button:** - [Icon: Find save] Save.

This button will save the translated text.

**Merge (button):** - [Icon: Find merge] Merge.

This button will merge the translated text.
