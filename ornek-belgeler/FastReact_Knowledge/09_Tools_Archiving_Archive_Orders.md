# Main Menu - Tools - Archiving - Archive Orders

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Archiving > Archive Orders
**Index keywords:** Archive Orders

---

## Archiving

This feature allows the User to Archive Orders so that they will not load and display Orders that have been marked as Archived. These Orders are still in FastReact and can be viewed by explicitly "calling" them, however they will not be loaded in to the Users cache memory. This removes "old" orders from the users PC memory and viewed lists on screen and in turn speeds up system performance and reduces the number of items a user needs to consider in lists.

### Archive orders

#### Search for orders to archive

Archiving can be done based upon a variety of criteria.

**Order reference:** Enter the name or code of the Order you want to Archive, or select an existing Order from the incremental search list.

**Product reference:** Enter the name or code of the Product you want to Archive, or select an existing Product from the incremental search list. This will display ALL Orders with that Product ready for Archiving.

**Customer:** Enter the name or code of the Customer you want to Archive, or select an existing order from the incremental search list. This will display ALL Orders with that Customer ready for Archiving.

**User defined field:** Select the name or code of the User defined field you want to Archive, or select an existing order from the incremental search list and then enter the UDF reference for the Orders you want to Archive. This will display ALL Orders with that User defined field ready for Archiving.

**Created date between:** Enter the Order created date range you want to Archive. This will display ALL Orders between those dates ready for Archiving.

**Latest delivery date:** Enter the Order delivery date range you want to Archive. This will display ALL Orders between those dates ready for Archiving.

**Find (button):** This button will display all the Orders available for Archiving based upon the criteria set above.

**Clear all settings (button):** This button will clear all the search criteria that has been set.

#### Search List

Once the Find button has been pressed the list of available Orders for Archiving will appear here.

**Order reference:** This is the name or code of the Order.

**Product reference:** This is the name or code of the Product.

**Customer:** This is the name or code of the Customer.

**Created date:** This is the date the Order was created.

**Latest delivery date:** This is the Latest delivery date of the Order, if the Order has multiple deliveries..

**To be archived:** This is a Yes/No label to let the User know if the Order has been selected to be Archived. By default, all the results of a Find will be marked with a "Yes".

> **Note:** Only Orders marked as complete can be Archived.

- [Icon: Select All] Select all.
- [Icon: Select Some] Invert selection.
- [Icon: Select None] Select none.

**Mark to be archived (button):** This button will mark the selected Order to be Archived by placing a "Yes" in the To be archived column.

**Not to be archived (button):** This button will mark the selected Order to be Archived by placing a "No" in the To be archived column.

**Archive selected (button):** This button will archive all Orders with a "Yes" in the To be archived column.
