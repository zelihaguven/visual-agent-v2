# Main Menu - Tools - Archiving - Archive Products

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Archiving > Archive Products
**Index keywords:** Archive Products

---

## Archiving

This feature allows the User to Archive Products so that they will not load and display Products that have been marked as Archived. These Products are still in FastReact and can be viewed by explicitly "calling" them, however they will not be loaded in to the Users cache memory. This removes "old" Products from the users PC memory and viewed lists on screen and in turn speeds up system performance and reduces the number of items a user needs to consider in lists.

### Archive products

#### Search for products to archive

Archiving can be done based upon a variety of criteria.

**Product reference:** Enter the name or code of the Product you want to Archive, or select an existing Product from the incremental search list.

**Product type:** Enter the name or code of the Product Type you want to Archive, or select an existing product Type from the incremental search list. This will display ALL Products with that Product Type ready for Archiving.

**Created date between:** Enter the Product created date range you want to Archive. This will display ALL Products between those dates ready for Archiving.

**User defined field:** Select the name or code of the User defined field you want to Archive, or select an existing order from the incremental search list and then enter the UDF reference for the Products you want to Archive. This will display ALL Products with that User defined field ready for Archiving.

**Find (button):** This button will display all the Orders available for Archiving based upon the criteria set above.

**Clear all settings (button):** This button will clear all the search criteria that has been set.

#### Search List

Once the Find button has been pressed the list of available Orders for Archiving will appear here.

**Product reference:** This is the name or code of the Product..

**Product type:** This is the name or code of the Product type.

**Created date:** This is the date the Product was created.

**To be archived:** This is a Yes/No label to let the User know if the Product has been selected to be Archived. By default, all the results of a Find will be marked with a "Yes".

- [Icon: Select All] Select all.
- [Icon: Select Some] Invert selection.
- [Icon: Select None] Select none.

**Mark to be archived (button):** This button will mark the selected Product to be Archived by placing a "Yes" in the To be archived column.

**Not to be archived (button):** This button will mark the selected Product to be Archived by placing a "No" in the To be archived column.

**Archive selected (button):** This button will archive all Product with a "Yes" in the To be archived column.
