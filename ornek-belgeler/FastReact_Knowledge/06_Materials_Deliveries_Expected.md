# Main Menu - Materials - Deliveries Expected

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Materials > Deliveries Expected
**Index keywords:** Deliveries Expected, Reservation

---

## Materials Availability

This option allows the user to manually enter expected material deliveries from suppliers.

### Materials

**Materials reference:** This is the name of the material that has already been entered into FastReact. Use the drop down button to select the required material or begin typing the material reference to use the incremental search facility.

**Supplier:** This is the name of the material supplier that has already been entered into FastReact. Use the drop down button to select the required supplier.

**Location:** This is the location of the material warehouse that the delivery will go to. Use the drop down button to select the required location.

**Reservation:** This option is available when the Reservation Licence option is enabled. This field is a user defined link between the Order and the Material Delivery.

#### Delivery table

This is the entry table for the material delivery.

**Delivery Date:** Enter in this column the expected delivery date of the material. You can enter multiple deliveries for each material/supplier/location.

**PO ref.:** The user can manually enter or import the PO reference for the delivery.

**Quantity:** Enter in this column the quantity of the material that is due on the delivery date.

**Available from:** This column will only appear if 'Handle material contracts and call offs' has been enabled during Setup.

Enter into this column the earliest date that the material will be available for delivery from the supplier. This will be used when FastReact calculates the material status of an order.

**In Transit:** This check box allows the User to mark a delivery as "on its way" to the Stock Warehouse or Factory.

**Update (button):** This button will update or save the current materials delivery.

**Expand dialog button:** - [Icon: Option] View material at all Locations for all Suppliers.

When selected the dialog will expand to show all deliveries for the selected Materials Reference from all suppliers and to which locations.
