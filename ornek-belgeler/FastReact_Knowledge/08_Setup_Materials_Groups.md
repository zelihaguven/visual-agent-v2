# Main Menu - Setup - Materials - Groups

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > Materials > Groups
**Index keywords:** Groups

---

## Material groups

FastReact allows you to manage a large number of materials each with a 50 character reference code.

Under this menu option the user can create and maintain a number of material groups. Try to keep the number of groups to a minimum else the benefit of the grouping mechanism will be lost.

For example, groups such as Fabric, Trims, Threads, Zips etc, could be created but subdividing Zips into subcategories might not be beneficial and defeat the object of grouping.

Materials groups are also used as part of the (optional) link between Critical Path events on an order and the materials required for each order.

### Define

This tab has an incremental search list and a button to insert a new group and another to delete and existing group. The user cannot delete a group that is attached to a material. The group name can be up to 15 characters long.

**Material group name:** A new or existing material group name can be entered here or selected from the drop down menu.

#### Options

**Recycled resource:** This option can be used to designate a particular material group as a recycling resource group.

**Delegate control to collaborative partner:** When Collaboration is enabled, and the material group will be one of the collaborative material group, the user can assign responsibility for that group to the collaborative partner.

**Roll control:** When the material stock module is enabled this option will allow the user to control stock by the Roll.

**Save (button):** This button will save the material group.

**Delete (button):** This button will rename the delete group. Only groups that have no materials attached to them can be deleted.

### Rename

Renaming of a Material Group can take place at any time. FastReact will prevent duplicate groups.

**Material group name:** This is a list of existing Material Groups. Select the Material group that requires renaming from the incremental search list.

**New name:** Enter a new Material group name here. FastReact will validate the new Material group and only allow a rename to be made if the new Material group reference does not already exist.

**Rename (button):** This button will rename the selected Material group.
