# Main Menu - Tools - Archiving - Un-archive Products

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Archiving > Un-archive Products

---

## Archiving

This feature allows the User to Unarchive Products so that they will load and display Products that had been previously marked as Archived.

### Unarchive orders

#### Search for Products to unarchive

Unarchiving can be done based upon a variety of criteria.

**Products reference:** Enter the name or code of the Products you want to Unarchive, or select an existing Products from the incremental search list.

**Product type:** Enter the name or code of the Product type you want to Unarchive, or select an existing Product type from the incremental search list. This will display ALL Products with that Product ready for Unarchiving.

**Created date between:** Enter the Products created date range you want to Unarchive. This will display ALL Products between those dates ready for Unarchiving.

**User defined field:** Select the name or code of the User defined field you want to Unarchive, or select an existing UDF from the incremental search list and then enter the UDF reference for the Products you want to Unarchive. This will display ALL Products with that User defined field ready for Unarchiving.

**Archived date between:** Enter the Products archived date range you want to Unarchive. This will display ALL Products archived between those dates ready for Unarchiving.

**Find (button):** This button will display all the Products available for Archiving based upon the criteria set above.

**Clear all settings (button):** This button will clear all the search criteria that has been set.

#### Search List

Once the Find button has been pressed the list of available Orders for Archiving will appear here.

**Products reference:** This is the name or code of the Products .

**Product type:** This is the name or code of the Product type.

**Created date:** This is the date the Products was created.

**To be unarchived:** This is a Yes/No label to let the User know if the Products has been selected to be Unarchived. By default, all the results of a Find will be marked with a "Yes".

- [Icon: Select All] Select all.
- [Icon: Select Some] Invert selection.
- [Icon: Select None] Select none.

**Mark to be unarchived (button):** This button will mark the selected Products to be Unarchived by placing a "Yes" in the To be unarchived column.

**Not to be unarchived (button):** This button will mark the selected Products to be Unarchived by placing a "No" in the To be unarchived column.

**Unarchive selected (button):** This button will Unarchive all Products with a "Yes" in the To be unarchived column.
