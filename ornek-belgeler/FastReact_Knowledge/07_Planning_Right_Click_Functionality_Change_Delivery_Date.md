## Change delivery date

[Screenshot: RC HL Change delivery date]

When selected the dialog screen below will open.

[Screenshot: RC HL Change delivery date]

This option allows the user to change the delivery date of the selected order directly form the planning board, the system will also generate a "possible" date for the order.

A possible date is the best estimated date based on where the order has been planned.
