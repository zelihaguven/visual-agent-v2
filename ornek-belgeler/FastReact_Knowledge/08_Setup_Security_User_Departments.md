## Department

### Department

**Department name:** This is the department to which the user belongs.

**Calendar:** This is the calendar, selected from the drop down list, to which the user will work.

**Capacity (FTE):** This is the amount of Full Time Equivalent staff that the department has.

**Insert/Update (button):** This button will insert and new department or update an existing one.

**Delete (button):** This button will delete the selected department.
