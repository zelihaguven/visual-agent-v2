# Main Menu - Update - Events by Event

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Update > Events by Event

---

## Update Event By Event

This option allows updating of both multiple events and multiple orders/products. This can simplify and speed up event updating by allowing you to update the same event(s) for several orders or products simultaneously.

This menu option has two main tabs, one for Production Events, and one for Development Events. Both have an identical layout and operation and will only be described once here.

### Production Events and Development Events

**Select All (button):** - [Icon: Select All] Select all.

This button selects all the events in the Select event(s) to update list.

**Invert Selection (button):** - [Icon: Invert Select] Invert selection.

This button inverts the last selection made.

**Select None (button):** - [Icon: Select None] De-select or select none.

This button de-selects all the events.

#### Select event(s) to update

Highlight the event(s) from the list that are to be updated.

**Enter order(s)/product(s) to be updated:** Enter the name of the order/product to be updated. Multiple items can be updated by entering a wild card pattern. See wild card matching.

**Select (button):** This button allows the selection of orders based upon the criteria entered in the, 'Enter order(s)/product(s) to be updated', field. A selection dialog will appear where all orders/products which match the requirements entered in the above field are listed. Orders/Products can then be selected or de-selected from the list.

**Update to date:** FastReact assumes that the updating of events occur on the day they actually happen and so this date automatically defaults to today. However another date can be selected if the user has rights. FastReact will record the system date as well as the selected completion date for the audit notes.

**Clear button:** Click here to clear the completion date (mark as not done) for the selected event(s) and order(s)/product(s).

**Update button:** Click here to update events to the selected date.

In both of the above cases FastReact will check to make sure the user has permission to update each event.

For example the planner may select a range of orders that span a number of different customers. They may be responsible for the selected events for one customer, and these events will be updated. If the planner is not responsible for events for another customer, these events will not be updated.
