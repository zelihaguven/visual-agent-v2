# Functionality - Pull forward - Limit by critical events

**Source:** FastReact Help (version 4.44) — Functionality / concepts
**Menu path:** Functionality > Limit by critical events
**Index keywords:** Critical events, Pull forward

---

## Pull Forward.

This option allows the planner to replan the strip/row/board based upon the critical events.

This will 'pull' the strip(s) forward so that the strip is planned one day before the critical event becomes late.

Warning:

Using this functionality may create gaps in the plan.
