## Grid Entry

*Context: Main Menu > Products > Grid Style Entry › Grid Entry*

The Grid Entry dialog allows the user to view, enter and modify data in a format to which they will be more accustomed to. This dialog is primarily designed to allow users fast data entry and modification.

> **Note:** The Grid Entry dialog does not have all the functionality of the Products Add/Amend dialog and as such may require the user returning to the Add/Amend dialog to alter data.

At present, The Grid Entry functionality cannot be used with sizes.

### Grid Entry

*Context: Main Menu > Products > Grid Style Entry › Grid Entry › Grid Entry*

**Find via Name:** This field allows the user to quickly find a desired Product from the list. The use of the '%' filter object greatly enhances this find and filter functionality.

**New (button):** This button will create a new line, in red, at the end of the Product List where a new Product can be entered.

**Copy (button):** This button will copy the currently highlighted Product in the Product List. The copied Product will appear at the end of the list and will be red until a unique Product name is entered and the order 'saved'.

**Delete (button):** This button will delete the currently highlighted Product .

#### Fixed Columns

*Context: Main Menu > Products > Grid Style Entry › Grid Entry › Grid Entry › Fixed Columns*

This is a list of all the Products within FastReact.

**Product:** This is the name or code of the Product. Fast React Systems advise using a consistent naming convention for orders as this will make future operations much easier. Fast React Systems strongly recommend that spaces are not used as part of the Product name.

#### Product Data Columns

*Context: Main Menu > Products > Grid Style Entry › Grid Entry › Grid Entry › Product Data Columns*

**Product Type:** Select a product type from the list. Attaching a product type to a product will allow the user to define working efficiencies by Group for your product.

**Description:** This is an optional entry of up to 50 characters long. It can be used to describe the type of product such as '100% cotton pleated trouser'. If a description is entered here then it will be used as the default description for orders that are subsequently created for this product.

**Created date:** This will be the system generated date on which the Product was created in FastReact.

**Customer:** Optionally, customers can be selected for the product.

**Timetable:** Selecting of a Development timetable allows the control of the development events for this product. This field will not be visible unless Development Event planning is enabled.

**Launch date:** This field is used in conjunction with the development timetable above. This date will be used when calculating event target dates using the offsets within the selected timetable.

**Property:** FastReact can help the planners to match individual Products to particular production lines, machines or factories. It does this by comparing properties for each row (machine) with codes that have been entered against each Product.

**Selling price:** Enter here the selling price per unit for this product.

**Material costs:** Enter here the cost per unit of all materials.

**Labour cost:** Enter here the cost per unit of labour.

**Other direct costs:** Enter here other costs per unit associated with the product, this could include processes outside your factory such as Embroidery, and Dyeing or a nominal unit value for fixed overheads.

**Size Set:** This is the name of the Size Set as defined on the Product Add/Amend dialog. This cannot be changed on the Grid Entry screen.

**User defined fields:** FastReact will allow the user to define other fields to suit their own particular circumstances. These fields can be given a value on a product by product basis. These can then be used for reporting purposes. These user defined fields must have already been created.

**Operation Work content:** This is a list of the operations that were created earlier. Enter the work content into the operations that have been defined. Work content must be entered against the planned operation to create a valid product. FastReact will prevent the saving of a product with zero work content. The work content is used by FastReact to calculate the amount of capacity required to produce a required quantity of the product.

> **Note:** At present, only one Route can be entered using Product Grid Entry.
