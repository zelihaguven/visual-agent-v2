# Main Menu - Tools - Review Change Log

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Review Change Log
**Index keywords:** Review Change Log

---

## There are "x" changes to review

FastReact is a multi user system and as such there will often be changes made to data by a number of different people. It is important for a planner to be aware of these changes as some could influence the decisions that need to be taken in the planning process. To help here FastReact provides a change review mechanism to identify all changes that have occurred within a specific time frame.

The change review list can be accessed and configured from the Tools menu, however, once configured this can also be shown when opening a planning board and when incorporating changes into an open board.

The dialog has two tabs, one to show the changes and the other to define your own personal preferences. These settings are individual to each FastReact user.

> **Note:** The change control mechanism is an integral part of FastReact and, as such, the left hand pane will always be able to display a list of changes. However, for the right hand pane to display what has changed on each item you must enable the Audit trail function which generates change notes automatically. If you do not have the Audit trail function enabled then please do not select any of the filter options.

### Change log

The left hand pane gives a list of orders and products that have been changed with each entry followed by the date on which the change was made.

> **Note:** The change date is taken from the system clock on each workstation and will be affected by the time zone in which the user is based; this clearly also relies on the fact that the clock is correct on that workstation.

The list is sorted so that the most recent changes are at the top.

The right hand pane contains details of the changes that have been made to the selected item. The format of these changes is exactly the same as in the Notes dialog.

### Preferences

Settings on this tab allow you to determine the scope and content of the change review.

#### Changes to recover

**Number of days to recover:** All change log entries are dated and this allows the planner to tell FastReact how far back to look for changes. This means that all changes that have occurred in the last day or week can be reviewed.

**Hide changes already seen this session:** When the planner first looks at the change log it will display all changes that have occurred within the period that has been selected (above). If enabled, this option will only return new change log entries and not those that have already been seen. This provides a convenient way of seeing only items that have changed. FastReact only remembers the changes that have been seen within a single session. So if FastReact is closed and then reopen it will show all the changes again.

#### Notes filter

**Number of history days to show:** The settings described above will select only those items that have changed within the specified period. However each item may have a long history of changes. Using this setting you can tell FastReact to show only the last few days of these changes so that you can concentrate on the most recent items.

##### Hide the following note types

FastReact categorises the notes into the options shown. Certain changes can be hidden if they are not required for viewing.

These note types are:

- Origination notes
- Changes
- Production updates
- Operation updates
- Event updates
- Strip notes
- User notes

#### Display changes

**When opening a planning board:** The change log will be checked when a low level or high level planning board is opened and this dialog will be displayed if there are any changes to review

**When refreshing data:** The change log will be shown when the planner clicks the planning board Refresh Data button and there are changes to review.

### Print log

**Print Change list (button):** Select this option to print the full change list as displayed on the Change log tab.

**Print current note (button):** If a certain order or product from the Change log has been selected then this button can opt to only print the changes on that order or product.
