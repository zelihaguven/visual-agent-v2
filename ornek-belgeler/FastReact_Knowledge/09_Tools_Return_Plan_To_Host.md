## Return Plan to Host

This option allows the remote plan to be returned to the host system. This function can also be run automatically, but this will need to be set up by the host system and is not configurable at the remote end.

**Create package:** Click here to create the data package that will be sent back to the host system.

**Send (button):** Click here to return the prepared package to the host system. If the package is sent several times the host will determine which is the latest data and only incorporate that package.

**Send and Request (button):** Click here to send back the prepared package as above, but also include a request for a new data package to be sent out from the host.

> **Note:** No more planning changes should be made until the new package has been received as these changes could be lost.
