# Main Menu - Setup - Security - Passwords

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > Security > Passwords
**Index keywords:** Passwords

---

## Set User Password

Each user must have their own password to gain access to FastReact. Passwords must be between 3 and 15 characters long and are not case sensitive. By default all newly created users will have the password of 'password' until they amend this.

Users can change their own passwords through this menu option. However, since most users do have access to the security menu they can access the password screen only by pressing [Ctrl-Alt-P].

### Password

**Enter current password:** You can only change your own password. To prevent unauthorised tampering, you must enter your current password to confirm you are who you say you are.

**Enter new password:** Enter a new valid password

**Enter again to confirm:** Enter the password again to confirm that you have the spelling correct.

**Update (button):** This button will update any changes on this dialog.
