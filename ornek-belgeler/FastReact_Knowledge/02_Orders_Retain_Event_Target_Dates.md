## Retain event target dates

### Retain event target dates

If this option is visible please contact your system Administrator or Fast React representative for clarification. This is a supervisor only option.

Please note:

This option should only be used with Supervisor rights during initial set up as every time the Retain targets button is click it will reset the target date for ALL orders. It is recommended that the Retain targets value is set on an Order by Order basis via the Orders Add/Amend dialog or via the Multiple Update option.
