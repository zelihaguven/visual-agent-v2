## MPS Configuration

FastReact can do MPS planning based upon certain user set criteria. Once the MPS has been run the results can be seen on the Planning board and viewed on the Plan Line Report.

The Plan Line methodology is explained here.

### Configure MPS

Imports can be started manually through this menu option, or can be triggered automatically to run at specified times of the day and days of the week.

A technical explanation of the import procedures may be found in the Reference Section.

**Demand period:** This drop down menu allows the user to select the Demand time period: Daily; Weekly or: Monthly.

**Forecast period:** This drop down menu allows the user to select the Forecast time period: Daily; Weekly or: Monthly.

**Select product:** This drop down menu allows the user to select a particular Product to run the MPS against or, if left with "\*" the MPS will be run against all Products.

**Run MPS with these settings (button):** This button will start save the above settings so that the next time MSP is run it will use these predefined settings.
