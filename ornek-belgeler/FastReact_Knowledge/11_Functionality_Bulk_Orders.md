## Bulk Order Processing.

The Bulk Order Processing function provides a way of consolidating multiple like orders into single orders within FastReact. The main focus of bulking is to maximise order sizes for production (own factory) or purchase (sourced manufacturer) allowing longer, more efficient production runs and therefore minimising internal production costs or reducing purchase price.

Each time the ‘Orders’ file is imported the detailed individual orders are stored in the ‘BULKORDERS’ table. This table is used to create a new ‘Orders’ import file containing the consolidated (bulked) orders. The new bulked file is imported and planned in FastReact in the normal way. It is possible to drill down into the bulked orders on the planning board to see details of the individual orders contained therein. The detailed orders that make up a bulked order can be viewed from Orders - Add/Amend - Bulk Details button.

### Bulk order details

Upon clicking of the Bulk Details button the dialog below will be displayed.

[Screenshot: Bulk Orders]

**Order Code:** These are the original Order Codes for the orders prior to bulking.

> **Note:** Bulk Order Processing will generate a new Order Code for the Bulked Order which can be viewed in the Order Add/Amend dialog. This code is generated by FastReact and based upon criteria set when Bulk Order Processing is configured.

**Product:** These are the original Product Codes for the orders prior to bulking.

**Customer:** These are the original Customer Names for the orders prior to bulking.

**Delivery date:** These are the original Delivery Date for the orders prior to bulking.

**DQ: n:** These are the original Delivery Quantities for the orders prior to bulking.

**Status:** These are the original Status for the orders prior to bulking.

Also in this dialog may be UDFs, Order Description, Sizes and Size Ratio. These fields will depend upon the system setup and the Bulk Order Processing configuration.

**Remove (button):** This will permanently remove the selected Order from the Bulked Order.

**Transfer (button):** This will allow the planner to transfer selected orders to either: a new Bulk Order; an Existing Bulk Order; or create a single Order.
