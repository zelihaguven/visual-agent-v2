## Linked order relationships

[Screenshot: LL RC Linked order relationship]

This option will only appear if the Prior / Next option is licenced on the user licence file. With this option licenced, clicking on the Linked order relationships will result in the dialog below. These relationships are setup on the Orders Add/Amend dialog in the Prior and Next fields.

[Screenshot: RC HL Linked order]

The above dialog is a graphical representation of the relationships between orders F_1000, P-130::PUC and T-190 as defined on the Orders Add / Amend dialog.
