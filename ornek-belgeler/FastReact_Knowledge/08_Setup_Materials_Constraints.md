## Constraint Setup

Based on the concept of constraints the Constraint Setup dialog will allow the user to setup and initialiise Constraints.

### Define

**Name/Code:** The constraint name or code.

**Description:** The constraint description.

**Consumed in section:** The section to which the material is consumed.

**Consumed at operation:** The section to which the material is consumed.

**Insert/Update (button):** This button will insert or update the material constraint.

**Delete (button):** This button will rename the delete constraint.

### Rename

Renaming of a constraint can take place at any time.

#### Select a constrain to rename

This is a list of existing Material Constraints. Select the Material group that requires renaming from the incremental search list.

**New name:** Enter a new Material group name here. FastReact will validate the new Material group and only allow a rename to be made if the new Material group reference does not already exist.

**Rename (button):** This button will rename the selected Material group.
