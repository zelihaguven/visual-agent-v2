# Main Menu - Reports - Page Selection Dialog

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Reports > Page Selection Dialog

---

## Select Print Options

### Page grid

This grid is has a cell for every page in the report. By default cells are Green indicating the page they represent will be printed. Red cells indicate that the relevant page will be skipped in the print out. There are a number of ways of selecting and de-selecting pages

**Click on a cell:** This will toggle the status between print and not print.

**Click on the row button at the left of the table:** This will toggle the status of all pages across the row.

**Click on the column button at the top of the table:** This will toggle the status of all pages down that column.

**Click on the very top left cell in the corner of the table:** This will toggle the status of every page in the report.

### Other print selection options

**Print all (button):** - [Icon: expand branch] Select all pages.

This will set all pages to be printed.

**Skip all (button):** - [Icon: contract branch] Skip all pages.

This will set all pages to be not printed.

**Select first (button):** - [Icon: Report print x pages] Print the first # of pages.

This will only print the first 'n' pages that are specified. However if there are any horizontal extension pages (a,b,c etc) these will be included as well.

**Print in reverse order:** Pages will be printed from the last to the first. This may be useful as the printer will put the last page at the bottom of the printed stack resulting in the report being sorted ready for use.

**Number of copies (button):** - [Icon: Report number of days] Select the number of copies.

This option allows the user to select the number of copies to be printer.

**Print (button):** Click to start the print process using your previously selected printer.

**Cancel Print (button):** Close this dialog without printing.

> **Note:** Once printing has started it can be cancelled by using the Cancel button on the Preview tool bar.
