# Functionality - Parallel Routings

**Source:** FastReact Help (version 4.44) — Functionality / concepts
**Menu path:** Functionality > Parallel Routings
**Index keywords:** Parallel Routings

---

## Product Routing.

Parallel Routings are user defined Routes on the Product through which its associated Order will pass. This will be reflected on the Planning Boards and Schedules.

### Define routings

**Product reference:** This is the Product Name of the selected Product for which the user wishes to define a Routing.

##### Routing sequence grid

This grid will hold the user defined Routing for the selected Product.

#### Stage list

This is a list of all the Stages through which the Product must pass. The Stage list holds all the Operations which have Work Content defined on the Products Add and Amend dialog. These stages are dragged on to the Routing sequence grid to form a route. Stages can be in parallel such the two or more stages happen at the same time.

**Save (button):** This button will save the user configured Routing.
