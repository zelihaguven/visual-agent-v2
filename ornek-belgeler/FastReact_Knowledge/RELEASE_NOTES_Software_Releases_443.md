We are pleased to announce the release of FastReact Evolve & Align 4.43 to all our customers. This new release is freely available to all users with a valid support and maintenance contract. Evolve 4.43 contains a range of new features, general enhancements, and fixes. You may already have an interim version containing some of these new options but may be unaware of all of the extra features. This release upgrades version 4.42.

New Enhancements and Additional Functionality

**Ref 16596 — Define text display on the planning board can now be re-sequenced.**

Functionality has been added to allow users to re-sequence the order of the entries in the define text display on the planning boards.

To re-sequence the define text display open the Define text display dialogue and use the arrows to move the entries in the Displayed data column up and down.

**Ref 16913 — Ability to move multiple orders in the loading bar charts.**

Users can now move multiple orders in the loading bar charts, previously this was restricted to moving one order at a time.

To move multiple orders, open the loading bar chart dialogue, select the orders to be moved and right click. The user can then move the orders to another available planning group.

**Ref 16689 — The ability view the supply from planned strips to the Material Query dialogue in a vertical system.**

The supply generated from planned orders for products that become materials for the next stage can now be viewed in the Material Query dialogue. The supply is listed as a delivery and the PO ref. column shows the FR order reference that is generating the supply. This gives the user full visibility of the material supply details in this display.

**Ref 16690 — The ability to open the Material Query dialogue from a supply strip in a vertical system.**

Users can now open the Material Query dialogue by right clicking on a supply strip and selecting ‘Supply details’ when using a vertical system.

**Ref 16473 — The ability to move and resize the Material detail dialogue.**

Users can now move and resize the Material detail dialogue giving the user extra flexibility in being able to view the planning board at the same time.

**Ref 16049 — The ability to select multiple strips by selecting the first and last strip on the same row using shift + ctr! + click.**

Multiple strips on a plan row can be selected by using shift + ctrl + click to select a first strip and using shift + ctrl + click to select an end strip. All strips between the two clicked strips will selected.

**Ref 16758 — Improvements to the High Level numeric display.**

The High Level numeric display has been improved to allow the Quantity, Output or Load to be displayed, previous functionality only allowed the Load to be shown.

A user can display either the Quantity, Output or Load in the High Level numeric display by right clicking and selecting the relevant option.

**Ref 16737 — The ability to specify a date format for a specific report.**

Users can now specify a date format on a report by report basis that overrides the existing report global setting. To specify a date format against an individual report, go to the layout tab and click in the top left corner of the report grid and select the format in the Date Formatting section.
