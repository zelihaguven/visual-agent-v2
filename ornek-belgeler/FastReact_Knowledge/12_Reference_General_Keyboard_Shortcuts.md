## Evolve/Align Keyboard Shortcuts

FastReact has a number of keyboard shortcuts to enhance the user experience:

### Main Menu

| Menu Name | Shortcut | | Menu Name | Shortcut |
|---|---|---|---|---|
| Exit | Alt + X + Enter | | Materials | Alt + M + Enter |
| Product | Alt + P + Enter | | Planning | Alt + L + Enter |
| Order | Alt + O + Enter | | Setup | Alt + S + Enter |
| Customer | Alt + C + Enter | | Tools | Alt + T + Enter |
| Update | Alt + U + Enter | | Repeat | Alt + A + Enter |
| Reports | Alt + R + Enter | | Help | Alt + H + Enter |
