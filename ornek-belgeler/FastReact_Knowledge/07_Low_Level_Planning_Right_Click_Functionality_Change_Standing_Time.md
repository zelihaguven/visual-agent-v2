## Change standing time

[Screenshot: LL RC Change standing time]

When selected the dialog screen below will open.

[Screenshot: LL RC Change standing time]

This option will allow the planner to change the length of production for an individual order or product. FastReact will take the factory defaults when first planned by the user can then amend these days through this function.
