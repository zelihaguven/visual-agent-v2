# Main Menu - Update - Event Failures

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Update > Event Failures
**Index keywords:** Event Failures

---

## Event failures

This dialog will list all incomplete events, based on orders, products or both. This allows the user to select an event and give a reason for its failure.

### Failed events

**Item to update (Order or Product):** Enter the order or product code in this box.

#### Search for

Searches can be filtered by orders or products.

#### Incomplete events for selected item

This will be a list of the incomplete events based upon the above code. Completed events will NOT appear in this list.

**Reason for failure:** If, for any reason, an event has failed this field allows for the input of that reason.

**Failures to date:** This keeps a running total of failures per order/product.

**Notes (button):** The failure reason will be held in the notes against the failed event.

**Update (button):** This button will update the event with the inputted Reason for failure.
