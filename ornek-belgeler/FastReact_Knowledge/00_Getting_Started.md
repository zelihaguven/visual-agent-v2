## Introduction

*Context: Getting Started › Introduction*

This document aims to guide the user through a typical configuration of FastReact.

It should be noted that this is a generic guide and as such it is designed to give the user a basic working model starting from scratch more for evaluation purposes rather than a true model of the business. Most of the advanced or detail configuration options are omitted from this document as they are not essential.

This document should not be used as a substitute for the correct configuration and user training by a qualified FastReact technician. The system is highly flexible and each installation is tailor configured to a particular business’ needs by a skilled expert.

# Setup - Configure - General

This area affects how FastReact will look and function overall. The basic options for reporting, importing and exporting data are defined in this area although it is not essential to have any of these configured to get a basic FastReact system working.

### Defaults

*Context: Getting Started › Introduction › Defaults*

None of these options are essential but typically you would enter the following

- Company name :- This appears on all reports.
- Week number :- show on the planning board and also reports if required
- Incremental search :- you would normally set these values to 1 for help in searching for records within FastReact.
- System audit trail notes :- when enable allows you to view the history of a product or order
- Late delivery calculation :- typically left as the default value 'arrive at customer'.

For more information on this section please refer to the help documentation.

# Setup - Configure - Production

This area is concerned specifically with detailed production planning. It is not essential to alter anything in this area, the default settings will allow a basic system to be configured.

### Startup

*Context: Getting Started › Introduction › Startup*

Of these values none are essential but you would typically set the following.

Build up Curves

These are used at low level planning only and would apply to a production line using a lot of manual labour where the operators need to learn skills and familiarity with new products.

Change allowance

These are used at low level planning only and would apply to a machine based setup such as dyeing, weaving, knitting, where an amount of down time for machine setup is required between different orders/styles. Please see help documentation for more details.

### Sections

*Context: Getting Started › Introduction › Sections*

A section would typically be the name of the operation that you are planning such as Sewing, Knitting, Weaving. Please refer to the help documentation for further details of this option.

# Setup - General - Routes

At least one route must be defined. FastReact will prevent access to other menus if this area has not been completed correctly.

### Define

*Context: Getting Started › Introduction › Define*

A route is linked to both a planning board group, row and a product. If one product can be made in two different factories, it may take longer to produce in one factory than the other. Alterative routes allow the same product to have different production times in different factories/suppliers. Please refer to the help documentation for further details of this option.

# Setup - General - Operations

At least one operation must be defined. FastReact will prevent access to other menus if this area has not been completed correctly.

### Define

*Context: Getting Started › Introduction › Define*

Operations represent the work flow of an order through production, therefore you must enter a list of operations. Each operation must be linked to a section previously entered. One of these operations must be a planned operation (the operation that is shown on the planning board) this would typically be 'Sewing' in apparel manufacturers. Please refer to the help documentation for further details of this option.

# Setup - General - Product Types

At least one Product Type must be defined. FastReact will prevent access to other menus if this area has not been completed correctly.

### Define - General

*Context: Getting Started › Introduction › Define - General*

Product Types are typically are high level product groupings such as Shirts, Trousers, Blouses in an apparel business. A more detailed product type list could be defined such as Ladies Blouse, Girls Blouse, Pleated Skirt, etc.

### Define - Operations

*Context: Getting Started › Introduction › Define - Operations*

For each product type entered you must select from the list which operations are used on this product type, for example the operation 'Embroider' would not be applicable to non embroidered product types.

# Setup - Planning - Plan Groups

At least one planning Group must be defined. FastReact will prevent access to other menus if this area has not been completed correctly.

### Define

*Context: Getting Started › Introduction › Define*

A plan group is normally a factory name or a group of machines. Type in a list of planning groups, and select the required values for this group from the Properties options.

The required fields are:

- Planning board to which this group belongs
- Planning section name
- Calendar name

Please refer to the help documentation for further details of this option.

### Operations

*Context: Getting Started › Introduction › Operations*

This option is essential if you are high level planning only, you must enter here the available capacity for each operation within the select group. See here (see: Main Menu > Setup > Planning > Plan Groups) for more information.

The low level planning the figures entered here are shown in the loading bar charts to compare capacity against loading on the pre and post planned operations.

# Setup - Planning - Plan Rows

This area is essential for low level planning boards but is not required for a High level planning only system.

### Define

*Context: Getting Started › Introduction › Define*

Plan rows are the resource that you will be planning. In an Apparel factory these would be production teams, in a Weaving plant these would be a list of machines available to plan.

The required fields are:-

- Group to which this row belongs
- Calendar to use
- Available capacity

Please refer to the help documentation for further details of this option.

# Setup - Event Planning - Framework

Depending on the settings entered under Setup-Configure-Event Planning you will get a tab labelled Production or Development or Both. You need to create at least one event under each tab, FastReact will prevent access to other menus if this area has not been completed correctly. To ensure that production can start on time you would normally enter 5-10 events that must happen before production can start.

### Production/Development – Events

*Context: Getting Started › Introduction › Production/Development – Events*

Type in a list of events and give these events an offset time based on the relative to point. Please refer to the help documentation, (Production or Development), for further details of this option.

### Production/Development – Dependant

*Context: Getting Started › Introduction › Production/Development – Dependant*

These values are none essential. Please refer to the help documentation, (Production or Development), for further details of this option.
