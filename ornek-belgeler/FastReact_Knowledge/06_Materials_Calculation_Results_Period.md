**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Materials > Calculation Results Period

---

## Calculation Results Period

When enabled via FRS this option will allow the user to select the MRP calculation period.

[Screenshot: MRPCalcPeriod]

This will allow the user to decide the calculation period when the MRP Calculation is run. The default value is Daily.
