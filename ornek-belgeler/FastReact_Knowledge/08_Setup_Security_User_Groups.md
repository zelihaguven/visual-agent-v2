# Main Menu - Setup - Security - User Groups

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > Security > User Groups
**Index keywords:** User Groups

---

## User Groups

FastReact has its own flexible security to control user access to it's various functions. This is separate to any network security that you may have already. Access rights to view, amend, add or delete both data and configuration settings can be controlled with some detail.

Access to FastReact is controlled through a user name and password. Only recognised Users with a valid password will be able to log into FastReact. Each User must belong to a User Group, however, a User may belong to more than one User Group.

Access rights to functions within Fast react are controlled at the User Group level. Users will have the access rights for any User Group to which they belong. Rights are additive so that Users will have all of the rights assigned to each User Group to which they belong.

User groups enable you to bring together certain users into a common logical collection. By assigning rights to this group any new users that are added to the group will have their access rights automatically defined.

This dialog will allow you to create, amend and delete Users groups and add users to these groups. By default this menu option will only be accessible to the system Supervisor or another user with Supervisor rights.

### Define

**Group name:** Enter a new group name to be created or select an existing user group to be deleted. Group names can be up to 15 characters long.

**Insert (button):** This button will insert a new user group.

**Delete (button):** This button will delete the selected user group. Groups that are deleted will have all links within FastReact removed. Confirmation of the deletion will be asked for before the group is deleted.

### Users

You can assign or remove users from user groups here.

#### Select a group from this list

Click on the list of groups to select it. The name of the selected group will be shown in the label at the top of the central list.

#### Has user members

This shows a list of users that are currently assigned to this group. Users can be removed by dragging them back to the list of users on the right, or by double clicking the user name.

#### Unassigned users

This is a list of users that are currently not assigned to the selected group. Users can be added to the group by dragging or double clicking the user name.

**Update (button):** This button will update a user group matrix.

### Rename

Renaming of a user group can take place at any time.

**Select a group to rename:** This is a list of existing groups. Select the group that requires renaming from the incremental search list.

**Enter a new name:** Enter a new group name here. FastReact will validate the new group and only allow a rename to be made if the new group reference does not already exist.

**Rename (button):** This button will rename the selected group.
