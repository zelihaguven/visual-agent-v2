# Functionality - Order Items

**Source:** FastReact Help (version 4.44) — Functionality / concepts
**Menu path:** Functionality > Order Items
**Index keywords:** Order Items

---

## Edit order items.

This option allows multiple customer orders to be attached to a single FastReact order.

### Order items

**FastReact order reference:** This is the order reference that is picked up from the Order dialog.

**Quantity:** This is the total quantity for the main FastReact Order.

#### Order List

This is a list of all the Order Items associated with the main Order.

**Customer:** This is the name of the customer for the Order Item rather than the main FastReact Order. The customer name must be a valid customer name from the drop down list.

**Customer ref.:** This is a free text field for entering a reference for the particular Order Item. The entries in this field must be unique for each Order Item in the list.

**Style:** This is a free text field for entering data regarding the particular Order Item.

**Due date:** This is the Item delivery date. This date MUST be before the main FastReact Order delivery date.

**Quantity:** This field will hold the Order Item quantity. This is the valid and positive order item quantity.

> **Note:** The total Order Items quantities MUST not exceed the total quantity for the main FastReact Order.

**Comment:** This text is optional.

**Save (button):** This button will save the edited Order Items.
