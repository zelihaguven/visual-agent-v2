## Transfer Production Updates

This dialog, when enabled, allows the User to transfer production from one Order to another.

### Transfer

**From order:** Select the Order from which to transfer production from.

**Order quantity:** The delivery quantity on this order.

**Reduce to:** What this Order production will be reduced to.

**Made to date:** The quantity of production that has been Made on this order.

**To order:** Select the Order from which to transfer production from.

**Order quantity:** The delivery quantity on this order.

**Max:** The maximum quantity that this Order can produce based upon the delivery quantity and the made quantity.

**Made to date:** The quantity already made on this Order.

**Transfer:** The quantity that is to be transferred to this Order.

**Transfer (button):** Clicking on this button will transfer the Production update.
