# Main Menu - Tools - Archiving - Un-archive Orders

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Archiving > Un-archive Orders
**Index keywords:** Archive Orders

---

## Archiving

This feature allows the User to Unarchive Orders so that they will load and display Orders that had been previously marked as Archived.

### Unarchive orders

#### Search for orders to unarchive

Unarchiving can be done based upon a variety of criteria.

**Order reference:** Enter the name or code of the Order you want to Unarchive, or select an existing Order from the incremental search list.

**Product reference:** Enter the name or code of the Product you want to Unarchive, or select an existing Product from the incremental search list. This will display ALL Orders with that Product ready for Unarchiving.

**Customer:** Enter the name or code of the Customer you want to Unarchive, or select an existing Customer from the incremental search list. This will display ALL Orders with that Customer ready for Unarchiving.

**User defined field:** Select the name or code of the User defined field you want to Unarchive, or select an existing UDF from the incremental search list and then enter the UDF reference for the Orders you want to Unarchive. This will display ALL Orders with that User defined field ready for Unarchiving.

**Created date between:** Enter the Order created date range you want to Unarchive. This will display ALL Orders between those dates ready for Unarchiving.

**Latest delivery date:** Enter the Order delivery date range you want to Unarchive. This will display ALL Orders between those dates ready for Unarchiving.

**Archived date between:** Enter the Order archived date range you want to Unarchive. This will display ALL Orders archived between those dates ready for Unarchiving.

**Find (button):** This button will display all the Orders available for Archiving based upon the criteria set above.

**Show orders that cannot be unarchived:** Checking this option will display Orders that cannot be Unarchived.

**Clear all settings (button):** This button will clear all the search criteria that has been set.

#### Search List

Once the Find button has been pressed the list of available Orders for Archiving will appear here.

**Order reference:** This is the name or code of the Order.

**Product reference:** This is the name or code of the Product.

**Customer:** This is the name or code of the Customer.

**Created date:** This is the date the Order was created.

**Latest delivery date:** This is the Latest delivery date of the Order, if the Order has multiple deliveries.

**To be unarchived:** This is a Yes/No label to let the User know if the Order has been selected to be Unarchived. By default, all the results of a Find will be marked with a "Yes".

- [Icon: Select All] Select all.
- [Icon: Select Some] Invert selection.
- [Icon: Select None] Select none.

**Mark to be unarchived (button):** This button will mark the selected Order to be Unarchived by placing a "Yes" in the To be unarchived column.

**Not to be unarchived (button):** This button will mark the selected Order to be Unarchived by placing a "No" in the To be unarchived column.

**Unarchive selected (button):** This button will Unarchive all Orders with a "Yes" in the To be unarchived column.
