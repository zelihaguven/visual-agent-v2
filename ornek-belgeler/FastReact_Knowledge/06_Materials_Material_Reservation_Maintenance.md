**Index keywords:** Material Reservation Maintenance

## Reservation Maintenance

This dialog allows the user to maintain the list of reserved materials and Order links. It allows the user to delete the Reservation.

> **Note:** Deleting a Reservation will remove that Reservation from all items that it is referenced. This process will not delete those items, just the Reservation field.

### Reservation Maintenance

This is a list of all the current Reservations within FastReact.

#### Reservation List

**Reservation name:** This shows the name of the Reservation..

**Order count:** This shows the number of Orders linked to that Reservation name.

**Stock count:** This shows the number of Stock entries linked to that Reservation name.

**Expected count:** This shows the number of Deliveries linked to that Reservation name.

**Delete Reservations (button):** This button will delete the selected reservation.

**Confirm Deletion (button):** This check box is a double check to make sure that the user wants to delete the selected reservation.
