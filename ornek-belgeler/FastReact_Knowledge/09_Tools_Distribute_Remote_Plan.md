# Main Menu - Tools - Distribute Remote Plan

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Tools > Distribute Remote Plan
**Index keywords:** Distribute Remote Plan

---

## Distribute remote plans

Sometimes known as Plug Out, Distributed Planning is a way of planning on a multi site environment.

### Distribute plans

**Package name:** This is the predefined name of the package to be distributed.

**Create package (button):** This will create the selected package.

**Send (button):** Click here to send the created package.

> **Note:** This function can be automated so that no manual intervention is required to send plans. See Main menu/Setup/Planning/Planning boards.

#### Send package

##### Progress

This will list the progress of the package being sent.

##### Status

This will advise on any warning or errors when sending the package

##### The following setup is only available if the FRS option Plug Out by Group is enabled.

### Configure

Click here to build the data package to send.

**Package name:** This is the predefined name of the package to be distributed.

**Save (button):** Click here to save the configuration.

#### General

**Select groups to include in this package:** Select the planning board that you want to distribute. The user to which the plan will be sent will be shown on the right. The user that the plan will be sent to is setup on the Planning Board – Distributed options dialog within the setup menu.

##### Options

**Send low level plans:** This will send the entire low level plans.

**Send high level plans:** This will send the entire high level plan.

**User limit:** This is the number of licenced remote users.

**Users assigned:** This is the number of remote users assigned a Distributed Plan.

**Users licenced:** This is the total number of licenced FastReact users.

#### Comms settings

**Send package by email:** Selecting this option will send the Distributed package via email.

**Send View Only package to FTP site:** Selecting this option will send a View Only package to the designated FTP site.

> **Note:** Only View Only Distributed Packages can be sent to FTP sites.

**Sent to email address:** The email address that the package has to be emailed to.
