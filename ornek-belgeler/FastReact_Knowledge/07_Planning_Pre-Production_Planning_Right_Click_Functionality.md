# Main Menu - Planning - Pre-production - Right Click Functionality

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > Pre-Production Planning > Right Click Functionality
**Index keywords:** Pre

---

The new Pre-production planning board now has some more right click options.

### Right click on Strip

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Right click on Strip*

[Screenshot]

## Definitions

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions*

#### Orders

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Orders*

[Screenshot]

This option will allow the user to "filter" the Pre-production planning board on the selected Order. In this case the Order is "S22". This means that the Pre-production board will only show Events for Order S22.

#### Product

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Product*

[Screenshot]

This option will allow the user to "filter" the Pre-production planning board on the selected Product. In this case the Product is "P10001". This means that the Pre-production board will only show Events for all Orders that have P10001 as their Product.

#### Product type

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Product type*

[Screenshot]

This option will allow the user to "filter" the Pre-production planning board on the selected Product Type. In this case the Product Type is "JACKETS". This means that the Pre-production board will only show Events for all Orders and Products that have JACKETS as their Product Type.

#### Update events dialog

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Update events dialog*

[Screenshot]

This option will display the Events dialog for the selected Order or Product.

#### Change the plan

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Change the plan*

[Screenshot]

This option will display the Change the plan dialog for the selected Order. This allows the user to, effectively replan the Order without having to open either the High Level or Low Level boards.

Using this function, the user can change the Complete date, the planned Group and the Transport method.

#### Order details

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Order details*

[Screenshot]

This option will display the Order Add/Amend dialog for the selected Order.

#### Order progress

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Order progress*

[Screenshot]

This option will display the Progress for the selected Order.

#### Product details

*Context: Main Menu > Planning > Pre-Production Planning > Right Click Functionality › Definitions › Product details*

[Screenshot]

This option will display the Product Add/Amend dialog for the selected Product.
