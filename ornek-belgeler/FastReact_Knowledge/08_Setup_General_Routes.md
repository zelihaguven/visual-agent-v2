# Main Menu - Setup - General - Routes

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Routes

---

## Routes

FastReact can be configured to take into account different production Routes for the same Product.

This is useful if your products can be made in different locations but these locations produce the goods via different methods, e.g. in apparel a factory may produce using the 'bundle' method and finish on-line where as another may use 'modular' manufacture and finish off-line. These two ways of making the same item can have different work content and so any Product can have several different work times for the same operation depending on the location selected to produce the Product. The same situation can also apply, less often, for materials requirements.

Each planning resource can be associated with one of the defined Routes and the rate of production or load on capacity will be determined by the work content of the Product for that Route. In addition if a Product has zero work content for a specific Route then it cannot be loaded to a planning resource that uses this Route

### Define

**Route name:** Enter a new Route name or select one from the list. Route names can be up to 15 characters long. Routes will be sorted alphabetically so it is important to name each Route carefully to ensure it is placed in preferential sequence.. The easiest way to do this is to start each Method with a number. It is good practice to leave a gap of 10 between each Method to allow insertions at a later date if necessary.

**Collaborative id:** When Collaboration has been enabled on the system, this option will appear. The routes that will be collaborated between the Host and the Remote systems will have the same id here.

**Insert / Update (button):** This button will either insert a new section or update an existing one.

**Delete (button):** This button will delete the selected section.

### Rename

Renaming of a route can take place at any time.

**Select an order to rename:** This is a list of existing routes. Select the route that requires renaming from the incremental search list.

**Enter a new name:** Enter a new route name here. FastReact will validate the new route and only allow a rename to be made if the new route reference does not already exist.

**Rename (button):** This button will rename the selected route.
