# Main Menu - Planning - Low Level Planning - Loading Bar Charts

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > Low Level Planning > Loading Bar Charts
**Index keywords:** Loading Bar Charts

## Loading bar charts

Whilst the planning board concentrates on planning of the main resource, the loading bar charts look in detail at this plan to identify problems of over or under loading on individual or groups of operations. By allowing a forward look, management have a better chance to revise production plans to smooth out any imbalances, or, if this is not possible, provides more time for contingency plans to be put into effect.

### Operation Loading

The bar charts are a graphical representation of the loading percentage per day/week or month. The charts have various configurable drop down menus, each of which will produce differing results on the graph.

##### Menu bar

- [Icon: Exit] Exit.
- [Icon: Calc] Recalculate.
- [Icon: ExpandContract] Expand or shrink date range.
- [Icon: Left Right Move] Scroll left or right.
- [Icon: Print report] Print chart.

**Group:** This drop down menu defines the group to which the loading chart represents.

**Operation:** This drop down menu defines the operation to which the loading chart represents.

**Planned time scale:** This drop down menu defines the planned time scale on which the loading chart is based. There are three time scale options: Planned per day; Planned per week and; Planned per month.

**Loading options:** This drop down menu defines the loading type on which the loading chart is based. There are three loading options: Percent loading; Absolute loading, and; Loading in units.

##### Options

This field has a selection of option which can be turned on or off.

**All operations:** With this option check the loading chart will show all of the available operations via a rotatable list to the right of the loading chart.

**Auto re-calc:** With this option checked the recalculation of the loading charts is done as soon as a change has been made. This option, when checked, will hide the re-calculate button on the menu bar.

**This group only:** If the system has shared capacity, this option will allow the planner to see the load for the selected group only rather than across the shared groups.

**Load:** - [Icon: Bar charts keys] Loading key.

The key to the loading colour on the bar chart are set up on the Planning Board Options dialog.

##### Bar Chart Sets

- [Icon: Bar charts] Bar chart button.
- [Icon: Bar charts sets] Bar chart drop down menu.

This licensable option allows the user to define, and save a set of bar charts against their Low Level Planning Board. Each set of saved Bar Charts is user specific. This means that every user could have a different selection of sets in the drop down menu.

**Hide all:** This option will hide all the chart within the displayed set. This allows the user to view the planning board without deleting the set. The set will reappear upon the re-opening of the particular planning board or see below.

**Restore all:** This option will restore the hidden bar charts to the planning board view.

**Add bar chart set:** This option will, when the bar charts have been configured, allow the user to save the bar chart setup on the planning board. A dialog will request a set name and this name will be added to the list below "default" for that user.

**Delete bar chart set:** This option will allow the user to delete their bar charts from the set list.

**Default:** This is the default set, which when the board is first opened will hold no bar charts, although charts can be saved against this set.

#### Allow operation group to be changed

This new licensable option will enable the planner to move operations from one group to another group, thereby equalising the loading for that operation.

When the operation is moved between groups, the original group name is retained in the new group.

The loading bar charts will automatically re-calculate the loading and redraw themselves. This function will only work if both of the operation loading dialogs have the, "re-calc", option enabled.
