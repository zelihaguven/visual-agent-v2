**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Planning > Low Level Planning

## Low level planning

When selected the chosen low level planning board will be displayed.

Unlike High Level Planning, Low Level Planning strictly enforces finite capacity. Orders are represented by coloured strips on a planning board where the colour represents the status or that order (e.g. Late, Materials problems) and the length represents the time in production.

The Low Level Planning Board allows the planner to plan in detail, to a specific production line, with build up allowances and so on. Any changes that are made at Low Level are reflected on the High Level plan, if the High Level Plan is available. See also Distributed Planning.

Each FastReact system can have multiple Low Level Planning Boards which could be used to reflect, different countries, continents, and/or factories. The amount of Low Level Planning Boards is dependant upon the licence options for the particular FastReact system.

The Low Level Planning Board has the following components:

- Accept List
- Grid Style Accept List
- Load list
- Grid Style Load List
- Sort function
- Row List
- Row Scale
- Row Scale Strip List
- Planning Board Icons
- Loading charts
- Low level rotational view
