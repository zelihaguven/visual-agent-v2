# Main Menu - Setup - Event Planning - Update Group

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > Event Planning > Update Group
**Index keywords:** Event Planning, Update Group

---

## Event Update Groups

It is now possible to assign users to a Group and have that Group responsible for n event.

### Define

This is where the Group names are defined.

**Group Name:** Enter the new Group name here.

#### Group name list

This is a list of all the Groups

**Insert (button):** This button will insert the new Group.

**Delete (button):** This button will delete the selected Group.

### Users

You can assign or remove users from user groups here.

#### Select a group from this list

Click on the list of groups to select it. The name of the selected group will be shown in the label at the top of the central list.

#### Has user members

This shows a list of users that are currently assigned to this group. Users can be removed by dragging them back to the list of users on the right, or by double clicking the user name.

#### Unassigned users

This is a list of users that are currently not assigned to the selected group. Users can be added to the group by dragging or double clicking the user name.

**Update (button):** This button will update Group.

### Rename

You can rename a timetable at any time.

#### Select a group from the list

This is a list of all the groups that have been created within the FastReact system.

**Enter a new name:** Once the group that has to be renamed has been selected, the new group name can be entered here.

**Rename (button):** This button will rename the group.
