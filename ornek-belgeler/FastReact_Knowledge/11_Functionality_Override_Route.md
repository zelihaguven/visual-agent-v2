## Override Route.

### How it works.

The idea behind this piece of functionality is to allow the Planner to define when a Route will change on the Planning board Row and have the subsequent strips take this change into consideration.

This Licenced option is enabled it can be selected via right clicking on the Low Level planning board selecting and selecting the "Override Route" option. Selecting this will display the following dialog:

[Screenshot: Override Route]

This dialog automatically picks up the Row and Group from the right click and will allow the planner to set a date and Route to be applied to the Planning board:

[Screenshot: Override Route]

In the above example, the Row will change its Route from "Default" to "Pieces" on the 24/04/2011 and then back to "Default" on the 23/04/2011. On the planning board this will be viewed as:

[Screenshot: Override Route]

The icons [Screenshot: Override Route] donate where the Route change starts and where it stops.
