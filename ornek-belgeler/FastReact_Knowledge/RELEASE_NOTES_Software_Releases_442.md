We are pleased to announce the release of FastReact Evolve & Align 4.42 to all our customers. This new release is freely available to all users with a valid support and maintenance contract. FastReact 4.41 contains a range of new features, general enhancements and fixes. You may already have an interim version containing some of these new options but may be unaware of all of the extra features. This release upgrades version 4.41.

The following document aims to highlight the main changes and enhancements plus a list of resolved issues. Some of the features and functions below are licenced options so if you have any questions regarding the features and fixes detailed in this document please contact your Account Manager to arrange an overview or a detailed training session.

*Context: Software Releases > 4.42 › 4.42 Sprint A*

New Enhancements and Additional Functionality

Functionality has been added to allow users to nominate existing reports as a report favourite allowing access directly from the report menu.

To use the report favourites functionality run the report you wish to nominate as a favourite and click on the star icon:

This will add the report to the report menu allowing the user to run the report without having to navigate through the report designer:

The report favourites can be organised and removed using the Organise Favourites menu option.

With flows enabled and strip peek view switched on the Actual Planned and Agreed Flow values are now displayed in the strip peek view. this gives additional flow information to the planner without having to open the flow dialogue.

Archived orders can now be purged as part of the standard order purge routine. Previously archived order would have to be un-archived prior to being purged making the process longer than it should be, this enhancement allows the order purge routine to include archived orders from a specified date.

To include archived orders in the order purge routine open the Purge Orders dialogue and tick the ‘Include archived orders from’ checkbox and specify a date to purge from.
