## Update Quality Recordings

This is a standalone dialog that records the reasons and quantities for shipping goods short to the customer.

### Short Shipments

#### Filter criteria

The dialog can be filtered on a variety of criteria:

- Order
- Delivery date
- Product
- Customer

**Recording date:** This is the date on which the short shipment details are recorded.

**Refresh (button):** Clicking on the Refresh button will populate the Order/Reasons matrix.

#### Order/Reason matrix

##### Order

**Order:** This is the Order name that meets the search criteria.

**Product:** This is the Product name for the Order that meets the search criteria.

**Customer:** This is the Customer name for the Order that meets the search criteria.

**Group:** This is the Group name where the Order, which meets the search criteria, is planned..

**Row:** This is the Row name where the Order, which meets the search criteria, is planned.

**Total:** This is the total quantity short shipped for the Order.

##### Reasons

**Late reason:** These will be the pre-defined reasons as to why the Order has been short shipped.
