The Status Lines at the bottom of the Low Level Planning Board, (see diagram below), relate to:

[Screenshot: LL bar]

**Order / Product / Product Type / Customer / Delivery / Colour / Materials / User Defined:** The fields are dependant upon the Rotation. Clicking on this field will rotate the board through the above settings.

When the mouse is moved over a strip the display shows:

**Order:** The Order Code.

**Product / Product Type (toggle):** The Product or Product Type of the Order.

**Earliest load:** This is the Earliest date that the Order can be loaded.

**Float:** The Critical Path days late.

**Load date:** The date that the load must be loaded by.

**Order description / Product description (toggle):** This is the description that is defined on the Order Add/Amend dialog or Product Add/Amend.

**Change mins, Work & Cal days / Change mins, Prodn & Cal days (toggle):** **Qty made, Started:** This is the amount which has been made to date.

**Quantity:** This is the quantity on the selected strip. It is totalled and also "split" where the cursor lies on the strip on the board.

**Customer:** The name of the Customer, as defined on the Order Add/Amend dialog.

**Delivery date:** This is the delivery date of the Order.

**Float:** The days late that the order will be, based upon the delivery date.

**Production end date / Last complete / Last complete from Factory / Last complete in warehouse (DC) / Last arrive at Customer (toggle):** This is the date on which production is due to end based upon the schedule.

**Transport details / User values (toggle):** This field describes the transport method through which the particular order must go through or the user value that is set by the user.

**Eff% Plan, Strip, Order, Result & (Daily):** This field describes the build up curve on the particular strip.
