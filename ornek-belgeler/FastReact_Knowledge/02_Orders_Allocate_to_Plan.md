# Main Menu - Orders - Allocate to Plan

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Orders > Allocate to Plan

---

## Allocate Orders To Planning Board

This option will only be available where there are multiple planning boards and High Level planning is not implemented.

### Allocate

#### Plan / section list

The left hand list will show the planning boards and sections that are available. Unless there is a large number or plans/sections the list will show them all without the need to scroll.

> **Note:** Only licensed sections will be shown.

Initially all list entries will be greyed out. This will change as orders are selected from the right hand order list.

#### Order list

This lists all orders that have not yet been allocated to a planning board. If the system has multiple sections, the section name will be appended to the order name and will be shown in the colour which has been selected for that section. Any parts of an order that have already been allocated to a plan will not be shown in this list.

Multiple orders can be selected from this list. Use the Shift key to select multiple consecutive orders or the Ctrl key to select multiple individual orders.

> **Note:** Multiple orders cannot be selected from different sections.

#### Allocate an order

To allocate an order to a planning board just click on it with the mouse and drag it to the Plan / Section list.

Drag the order(s) to the required planning board and release the mouse button. FastReact will not allow an order to be dropped on an invalid planning board or section.

> **Note:** This will not update your data in any way, but will create a list of temporary allocations, which can be saved as below.

### Save allocations

This tab will become visible if there are any allocations that need to be saved.

#### Select allocations to be saved (use CTRL or Shift key to multiple select)

This is a list of orders and the planning board to which each has been allocated. By default all allocations will be ticked and can be saved just by clicking the Save button at the bottom of the Allocation list. However, FastReact will allow the editing of this list so that only some of the allocations can be updated.

There are a number of ways to do this:

- [Icon: Select All] Select all.

**Select all (button):** This button will select all orders

- [Icon: Invert Select] Invert selection.

**Invert selection (button):** This button selections that are made will be de-selected, others will be selected. This is useful if you want to select all but a few orders. You select these and then click the Invert button.

- [Icon: Select None] Clear selection.

**Clear selection (button):** This button will deselect all orders.

#### Select individual orders

Individual orders can be selected with the mouse. Whichever order you click on will be selected, whilst all others will be de-selected.

#### Select multiple orders

Click on the first order to select then hold the Ctrl key down and select others

#### Select a range of orders

Click on the first order in the range and then hold the Shift key down. Select the last order in the range and all others in between will be selected.

**Save allocations (button):** This button will save the selected orders. If all orders have been selected FastReact will return to the Allocate tab.

### Close

Attempting to close the dialog whilst there are allocated orders to save will result in a dialog asking for confirmation. Press Yes to go to the Save allocations tab of No to close and lose any temporary allocations.
