# Reference - Importing Data - Material Contracts

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > Import Data > Material Contracts
**Index keywords:** Material Contracts

---

Material contracts may be imported from a file called MATCONTR.txt or MATCONTR.csv.

The following fields may be imported. Essential fields are shown in bold.

| Field _ Name | Type | Description |
|---|---|---|
| **M.CODE** | T50 | The unique material code. This field size can be increased. Click here (see: Main Menu > Setup > Configure > General) for more information. |
| **M.LOCATION** | T15 | The location where the material stock is to be delivered. ( This must be a valid location ). |
| **M.DELDATE** | Date | The contract end date / delivery date of the specified material. |
| **M.DELQTY** | Float | Outstanding contract balance. |
| M.ECOD | Date | The earliest availability ( Call off ) date of the specified material from the supplier. |
