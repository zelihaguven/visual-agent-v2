# Reference - General - Incremental Search List

**Source:** FastReact Help (version 4.44) — Reference
**Menu path:** Reference > General > Incremental Search List

---

## I ncremental Search List

FastReact provides a convenient way of finding items (orders, products, materials and so on) without having to type in what could be a long reference code. This is the incremental search list.

To use this facility just start to type the first characters of the required item. As the user types FastReact will compare the entry so far with all items and give a list of just those which match the entered characters. This list will become visible just underneath the entry field. As the user types in more characters the list will become shorter and eventually the user will be able to select the required item. This is done by clicking with the mouse, or using the keyboard, by pressing the down arrow key until the required item is highlighted then pressing the Tab key. The list will be hidden automatically.

The list may be filled with all entries by entering an asterisk or by clicking the blue button just to the right of the list. The user can then scroll through all items with the keyboard as described above. Double click on the asterisk in the entry field to clear the fields and hide the list.

Configuration

If the list contains many items then filling the list may cause a noticeable delay in responding to new characters. This would not normally be a problem unless there are many thousands of items to search or the computer is particularly slow. To improve response time you can limit the number of entries returned in the list to say 100 or 1000.

Another way of improving response and usefulness is to disable the search function until a specified number of characters has been entered.

For example, if all of your orders started with 'WO' then there would be no point searching until at least 3 characters had been entered as all orders would be returned to the list.
