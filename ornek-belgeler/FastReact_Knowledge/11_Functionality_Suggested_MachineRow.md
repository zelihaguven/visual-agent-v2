## Suggested Machine/Row

This functionality allows the planner to see where previous Orders/Batches have been planned. They can also see the achieved efficiency for those Orders/Batches. This allows the planner to select the appropriate machine/row on to which the new Order/Batch will be planned.

Only Orders/Batches which have been updated will appear on this list.

[Icon: Func Suggested Machine]

Notice that there is a new option ‘Show where product has been previously made’. Enabling this option will add an enhancement to the Load List.

 [Icon: Func Suggested Machine]

As can be seen from the above diagram, there is a new section to the right of the standard Load List called Production History. The details of this will hold the Date, Group, Row, Quantity and Order of previously planned Orders/Batches which use the same product code as the currently selected Order/Batch. In the above example no Orders/Batches have been previously planned and updated with Product Code P10001.

The diagram above clearly shows the details of previously planned and updated Orders/Batches which have P10001 as their product code.

### The Product History.

Note that the title ‘Product History’ is underlined. This indicates that there are multiple updates for these particular entries. Double clicking on the entries on the right hand side will display all the updates. This can then be filtered or sorted to show what the user needs to see. See diagram below:

 [Icon: Func Suggested Machine]

This does not mean to say that the Planner has to plan the Order/Batch on this Machine/Row.
