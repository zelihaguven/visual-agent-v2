# Main Menu - Setup - General - Currencies

**Source:** FastReact Help (version 4.44) — User manual
**Menu path:** Main Menu > Setup > General > Currencies
**Index keywords:** Currencies

---

## Currencies

FastReact can work with multiple currencies in some of its modules.

**Add currency:** Enter the name of the Currency.

**Save (button):** This button will save the entered Currency.

**Rename currency:** Select the Currency to be renamed.

**Rename (button):** This button will rename the selected Currency with the New Currency.

**New name:** The new name of the Currency.

### Exchange Rates

**Currency:** A drop down list of Currencies within FastReact.

**New Rate (button):** This button will allow the User to enter a new Exchange Rate against the selected Currency.

**Update (button):** This button will allow the User to enter a new Exchange Rate against the selected Currency.

#### Exchange Rate List

This List will be a historical record of Exchange rates for the selected Currency.

**Exchange Date:** This date is automatically entered when the New Rate button is clicked, the date is always "todays" date.

**Exchange Rate:** Upon pressing the New Rate button the User will be able to enter and Exchange Rate.
