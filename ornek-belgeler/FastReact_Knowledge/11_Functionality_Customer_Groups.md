# Functionality - Customer Groups

**Source:** FastReact Help (version 4.44) — Functionality / concepts
**Menu path:** Functionality > Customer Groups
**Index keywords:** Customer Groups

---

## Customer Groups.

This licence option will, when configured correctly, allow the FR administrator to set security options, based upon Customers, for each user.

> **Note:** The maximum number of Customer Groups allowed within FastReact is 100.

For example, in FastReact the user Peter can be configured to only show Customers that he is responsible for.

There are three levels of security:

- Full access – this will allow the user to change anything for any Customer that is part of that Customer group.
- View only – this allows the user to view, but not change any Customers that are part of that Customer group.
- Hidden – this will hide all Customers that are part of that Customer group.

#### Full access

This option will allow the user full access to ALL aspects of Customer Groups within FastReact that are set as such.

This includes the Order dialog, CP planning board, HL planning board, the LL planning board and all find facilities.

#### View only

This option will allow the user view only access to ALL aspects of Customer Groups within FastReact that are set as such.

This includes the Order dialog, CP planning board, HL planning board, the LL planning board and all find facilities.

However, for those Groups marked as View Only, the user will not be able to change anything as the Update button, on the dialogs will be disabled, and the strip on the boards will be locked.

#### Hidden

This option will hide ALL aspects of Customer Groups within FastReact that are set as such. In other words any Group that are set as Hidden will be hidden from view for those users that are marked as Hidden.

### Customers

Customer Groups are setup on the Customers dialog and assigned to a Customer there. If a customer has no Group then full access will be given to all users.

### Security - Users

The access levels are set for each Customer Group against each User.

> **Note:** If a user has no access level set against a Group then, by default, they will have full access to all aspects of that Group.

These are set on the Customer Groups tab on the User dialog.
